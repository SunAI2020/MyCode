# IP渗透测试工具

## 功能介绍

这是一个基于Python的IP地址渗透测试工具，提供了命令行和GUI版本，用于对指定IP地址进行端口扫描、服务识别和漏洞扫描。

### 主要功能

1. **端口扫描**：扫描指定IP地址的端口范围，检测开放的端口
2. **服务识别**：根据常见端口识别运行的服务
3. **漏洞扫描**：检测常见的安全漏洞
4. **报告生成**：生成详细的扫描报告
5. **GUI界面**：提供直观的图形用户界面，提高用户体验

### 支持的服务和漏洞

- **FTP (21)**：可能存在匿名访问漏洞
- **SSH (22)**：可能存在弱密码漏洞
- **Telnet (23)**：明文传输漏洞
- **SMTP (25)**：开放中继漏洞
- **DNS (53)**：域名系统服务
- **HTTP (80)**：可能存在XSS或SQL注入漏洞
- **HTTPS (443)**：可能存在SSL/TLS漏洞
- **MySQL (3306)**：可能存在弱密码或远程访问漏洞
- **RDP (3389)**：可能存在暴力破解漏洞
- **PostgreSQL (5432)**：可能存在弱密码漏洞
- **Redis (6379)**：未授权访问漏洞
- **MongoDB (27017)**：未授权访问漏洞

## 使用方法

### 命令行版本

```bash
python ip_penetration_test.py
```

### GUI版本

```bash
python ip_penetration_test_gui.py
```

### GUI界面使用步骤

1. **启动程序**：运行 `ip_penetration_test_gui.py` 文件
2. **输入目标IP**：在"目标IP"输入框中输入要扫描的IP地址
3. **设置端口范围**：在"端口范围"输入框中设置要扫描的端口范围（默认1-1000）
4. **设置超时**：在"超时(秒)"输入框中设置连接超时时间（默认1秒）
5. **开始扫描**：点击"开始扫描"按钮开始扫描过程
6. **查看结果**：在结果标签页中查看扫描结果，包括开放端口、服务识别和漏洞扫描
7. **保存报告**：点击"保存报告"按钮将扫描结果保存为JSON格式的报告
8. **清空结果**：点击"清空结果"按钮清空当前的扫描结果
9. **停止扫描**：在扫描过程中点击"停止扫描"按钮停止扫描

## 技术实现

- **核心功能**：使用socket库进行端口扫描，使用多线程提高扫描速度
- **GUI框架**：使用tkinter库构建图形用户界面
- **报告生成**：使用JSON格式生成扫描报告
- **错误处理**：实现了完善的错误处理机制
