# 代码安全审计工具 - GUI版本

## 功能介绍

这是一个基于Python的代码安全审计工具，提供了图形用户界面(GUI)，用于检测代码中的常见安全漏洞和风险。

### 主要功能

1. **多语言支持**：支持Python、Java、C/C++、JavaScript等多种编程语言
2. **文件和目录审计**：可以审计单个文件或整个目录
3. **自定义规则**：支持通过JSON文件自定义安全规则
4. **实时结果显示**：在表格中实时显示审计结果，包括文件路径、行号、问题描述和代码片段
5. **报告生成**：支持将审计结果保存为JSON格式的报告
6. **后台处理**：使用线程进行后台审计，避免界面卡顿

### 检测的安全漏洞

- **SQL注入**：检测可能导致SQL注入的代码模式
- **XSS攻击**：检测可能导致跨站脚本攻击的代码模式
- **硬编码密码**：检测代码中的硬编码密码和密钥
- **不安全的哈希算法**：检测使用MD5、SHA1等不安全哈希算法的代码
- **缓冲区溢出**：检测C/C++中的缓冲区溢出漏洞
- **eval函数使用**：检测Python中使用eval函数的代码

## 使用方法

1. **启动程序**：运行 `code_security_audit_gui.py` 文件
2. **选择目标**：点击"浏览文件"或"浏览目录"按钮选择要审计的文件或目录
3. **配置规则**：（可选）点击"浏览"按钮选择自定义规则文件
4. **设置输出**：（可选）点击"浏览"按钮设置审计报告的保存路径
5. **开始审计**：点击"开始审计"按钮开始审计过程
6. **查看结果**：在结果表格中查看审计发现的问题
7. **清空结果**：点击"清空结果"按钮清空当前的审计结果

## 界面说明

- **配置区域**：用于设置审计目标、规则文件和输出路径
- **按钮区域**：包含"开始审计"和"清空结果"按钮
- **状态栏**：显示当前操作状态和结果
- **结果表格**：显示审计发现的问题，包括文件路径、行号、问题描述和代码片段

## 技术实现

- **GUI框架**：使用tkinter库构建图形用户界面
- **安全检测**：使用正则表达式检测代码中的安全漏洞
- **后台处理**：使用线程进行后台审计，避免界面卡顿
- **报告生成**：使用JSON格式生成审计报告
