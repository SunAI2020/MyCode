# 员工考勤程序

## 功能介绍

这是一个基于Python的员工考勤管理程序，提供了直观的图形用户界面，用于管理员工信息、记录考勤和生成统计报表。

### 主要功能

1. **员工管理**：添加、编辑、删除员工信息，包括姓名、部门、职位和联系电话
2. **考勤管理**：记录员工的考勤状态（出勤、缺勤、迟到、请假）、上下班时间、加班小时和备注
3. **统计报表**：生成员工考勤统计报表，包括总天数、出勤、缺勤、迟到、请假和加班小时
4. **数据持久化**：自动保存数据到JSON文件，确保数据不会丢失
5. **用户友好界面**：使用tkinter构建的直观图形界面，操作简单易用

## 使用方法

### 启动程序

```bash
python employee_attendance.py
```

### 员工管理

1. **添加员工**：点击"员工管理"标签页，然后点击"添加员工"按钮，填写员工信息并保存
2. **编辑员工**：在员工列表中选择员工，点击"编辑员工"按钮，修改信息并保存
3. **删除员工**：在员工列表中选择员工，点击"删除员工"按钮，确认后删除

### 考勤管理

1. **选择员工**：在"考勤管理"标签页的下拉框中选择员工
2. **选择日期**：在日期输入框中输入要记录的日期（格式：YYYY-MM-DD）
3. **获取记录**：点击"获取记录"按钮查看该员工当天的考勤记录
4. **填写考勤信息**：选择考勤状态、输入上下班时间、加班小时和备注
5. **保存记录**：点击"保存考勤记录"按钮保存考勤信息

### 统计报表

1. **选择员工**：在"统计报表"标签页的下拉框中选择员工
2. **选择日期范围**：输入开始日期和结束日期
3. **生成报表**：点击"生成报表"按钮查看统计结果
4. **查看详细记录**：在下方表格中查看该时间段内的详细考勤记录

## 技术实现

- **核心功能**：使用Python实现员工管理、考勤记录和统计功能
- **数据存储**：使用JSON文件存储员工信息和考勤记录
- **GUI框架**：使用tkinter库构建图形用户界面
- **数据处理**：使用Python标准库进行日期处理和数据操作
