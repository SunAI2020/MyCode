## 🖼️ Logo 图片位置

**文件路径：** `/home/admin/.openclaw/workspace/vuln-scanner/assets/logo.png`

**如何添加公司商标：**

```bash
# 方法 1：使用设置脚本
cd /home/admin/.openclaw/workspace/vuln-scanner
./setup_logo.sh

# 方法 2：手动复制
cp /path/to/your/logo.png \
   /home/admin/.openclaw/workspace/vuln-scanner/assets/logo.png
```

**注意：** 如果没有提供 logo.png，GUI 会自动显示文字 Logo（盾牌图标 + 对勾）。
