# 代码安全审计工具 - 集成Claude Code Security

## 功能介绍

这是一个基于Python的代码安全审计工具，集成了Claude Code Security的安全分析能力，用于检测代码中的常见安全漏洞和风险，并使用Claude进行智能安全分析。

### 主要功能

1. **多语言支持**：支持Python、Java、C/C++、JavaScript等多种编程语言
2. **文件和目录审计**：可以审计单个文件或整个目录
3. **自定义规则**：支持通过JSON文件自定义安全规则
4. **实时结果显示**：在表格中实时显示审计结果，包括文件路径、行号、语言、问题描述和代码片段
5. **统计图表**：使用饼图和柱状图直观展示漏洞分布情况
6. **Claude安全分析**：使用Claude API对扫描结果进行智能安全分析，提供专业的安全建议
7. **报告生成**：支持将审计结果保存为JSON格式的报告
8. **后台处理**：使用线程进行后台审计，避免界面卡顿

### 检测的安全漏洞

- **SQL注入**：检测可能导致SQL注入的代码模式
- **XSS攻击**：检测可能导致跨站脚本攻击的代码模式
- **硬编码密码**：检测代码中的硬编码密码和密钥
- **不安全的哈希算法**：检测使用MD5、SHA1等不安全哈希算法的代码
- **缓冲区溢出**：检测C/C++中的缓冲区溢出漏洞
- **eval函数使用**：检测Python中使用eval函数的代码

## 使用方法

### 命令行版本

```bash
python code_security_audit_with_claude.py
```

### GUI版本

```bash
python code_security_audit_with_claude_gui.py
```

### GUI界面使用步骤

1. **启动程序**：运行 `code_security_audit_with_claude_gui.py` 文件
2. **选择目标**：点击"浏览文件"或"浏览目录"按钮选择要审计的文件或目录
3. **配置规则**：（可选）点击"浏览"按钮选择自定义规则文件
4. **设置输出**：（可选）点击"浏览"按钮设置审计报告的保存路径
5. **输入Claude API密钥**：（可选）在"Claude API密钥"输入框中输入Anthropic Claude API密钥，用于安全分析
6. **开始审计**：点击"开始审计"按钮开始审计过程
7. **查看结果**：在结果标签页中查看审计发现的问题，包括问题列表、统计图表和Claude安全分析
8. **清空结果**：点击"清空结果"按钮清空当前的审计结果

## 技术实现

- **核心功能**：使用正则表达式检测代码中的安全漏洞
- **安全分析**：使用Claude API进行智能安全分析，提供专业的安全建议
- **GUI框架**：使用tkinter库构建图形用户界面
- **数据可视化**：使用matplotlib库生成统计图表
- **后台处理**：使用线程进行后台审计，避免界面卡顿
- **报告生成**：使用JSON格式生成审计报告

## 获取Claude API密钥

要使用Claude安全分析功能，需要获取Anthropic Claude API密钥：

1. 访问 [Anthropic控制台](https://console.anthropic.com/)
2. 注册或登录账户
3. 创建API密钥
4. 将API密钥复制到工具的"Claude API密钥"输入框中
