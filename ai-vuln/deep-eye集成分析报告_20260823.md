# deep-eye 漏洞检测能力深入分析与 AI-VULN 集成报告

> 日期：2026-08-23
> 来源：https://github.com/zakirkun/deep-eye （版本 1.4.0，MIT License）

## 一、结论摘要

deep-eye 是一个 **AI 驱动的主动 Web 渗透测试工具**（Python 3.8+，requests + ThreadPoolExecutor，多 AI 供应商）。它内置 **50+ 主动 Web 漏洞检测项**，核心分为三层：

1. **内置 `_check_*` 方法（23 类经典注入/配置/泄露检测）** —— 自包含、零外部依赖。
2. **feature testers（28 个深检测模块）** —— 其中 6 个自包含、零外部依赖；其余依赖 Playwright/Frida/mitmproxy/OAST/RAG/Nuclei 等外部工具。
3. **流水线服务（recon/AI 规划/AI 分诊/证据摘要/合规映射/报告等）** —— 与 AI-VULN 现有能力重叠或依赖外部服务。

本次集成按确认范围 **「精选自包含检测」**，将 deep-eye 中 **自包含、零新依赖** 的能力移植到 AI-VULN，落地为 `web_vuln_scanner.py`，并接入现有 Web 扫描引擎与 REST API。

**已移植 29 类主动检测**，与 AI-VULN 现有能力互补：

| 能力层 | AI-VULN 现状 | deep-eye 补齐 |
|--------|-------------|--------------|
| 网络扫描/CVE 匹配/0day | ✅ 已成熟（scanner_engine.py） | — |
| 代码审计 | ✅ 已成熟（ai_analyzer.py） | — |
| Web 被动扫描 | ✅ 指纹/高危路径/目录/ZAP（web_scanner.py） | — |
| **Web 主动漏洞检测** | ❌ 空白 | ✅ **本次补齐（29 类）** |

## 三、代码架构分析（deep-eye 侧）

```
deep_eye.py (CLI)
  └─ core/scanner_engine.py       # 生命周期、爬取、OpenAPI、后处理
       └─ core/vulnerability_scanner.py  # 23 个 _check_* + _feature_testers 分发
            ├─ core/injection_surfaces.py  # 多注入面发现 + 注入派发（纯 stdlib）
            ├─ modules/<name>/tester.py    # 28 个 feature testers
            └─ utils/http_client.py        # requests 包装（重试/限流/UA轮换）
```

**关键契约（本次移植遵循）：**
- 模块接口：`scan(url, context=None) -> list[dict]`
- 结果字段：`type / severity(critical..info) / url / parameter / payload / evidence / description / remediation`
- `injection_surfaces`：从 query/form/json/cookie/header/path 六个注入面发现参数并派发注入。

## 四、AI-VULN 集成实现

### 4.1 新增 `web_vuln_scanner.py`（核心引擎）

- `Surface` 枚举 + `extract_surfaces()` + `inject()`（移植自 injection_surfaces，纯 stdlib）
- `SafeHTTPClient`（requests.Session 适配器：verify=False、统一 UA/timeout，提供 get/post/head/options/request）
- `WebVulnScanner`（29 类检测，`scan(url, enabled_checks=None, progress_callback=None)`）
- 结果归一化为 AI-VULN finding：`{scan_type, category, title, severity, detail, evidence, url, parameter, payload, remediation}`

### 4.2 接入链路

```
WebSecurityScanner.scan(target_url, do_active=True)   # web_scanner.py
  ├─ 指纹 → 高危路径 → 目录枚举 → ZAP（原有被动链路）
  └─ WebVulnScanner.scan()（新增主动链路）→ result['active']
        └─ _aggregate_findings() 并入 findings → _persist() 写 web_scan_results

POST /api/webscan (do_active: true)                   # api/routers/webscan.py
  └─ WebScanRequest.do_active → _run_web_scan → scanner.scan(...)
```

### 4.3 数据库变更

`web_scan_results` 表新增 `parameter TEXT`、`payload TEXT` 两列（幂等 `ALTER TABLE` 迁移，兼容旧库）。

## 六、使用方式

```python
# 独立引擎
from web_vuln_scanner import WebVulnScanner
scanner = WebVulnScanner()
findings = scanner.scan('https://target.example')

# 完整 Web 扫描（被动 + 主动）
from web_scanner import WebSecurityScanner
result = WebSecurityScanner(db=db).scan('https://target.example', do_active=True)
```

```bash
# REST API
curl -X POST http://127.0.0.1:8000/api/webscan \
  -H "X-API-Key: <key>" -H "Content-Type: application/json" \
  -d '{"target_url":"https://target.example","do_active":true}'
```
