一、概述

本次改动将开源项目 deep-eye（https://github.com/zakirkun/deep-eye）中 自包含、零新依赖的主动 Web 漏洞检测能力移植到 AI-VULN，填补了 AI-VULN 在 Web 主动漏洞检测 上的空白。

  • 29 类主动检测：23 类经典注入/配置/泄露检测 + 6 类深检测（JWT/CORS-CSP/SSRF云元数据/SSTI多引擎/IDOR/NoSQL）。
  • 零新依赖：仅复用项目已用的 requests + Python 标准库。
  • 接入现有链路：挂到 WebSecurityScanner.scan() 的 do_active 阶段，与既有被动扫描串联，结果统一落库。

三、详细改动说明

3.1 web_vuln_scanner.py（新增）

主动 Web 漏洞检测核心引擎，移植自 deep-eye 的自包含检测能力，适配 AI-VULN 约定。

组件说明
Surface 枚举 + extract_surfaces() + inject()多注入面发现与派发（query/form/json/cookie/header/path），纯 stdlib
SafeHTTPClientrequests.Session 适配器，get/post/head/options/request，verify 可配置
WebVulnScanner29 类检测编排器，scan(url, enabled_checks=None, progress_callback=None)
_normalize()deep-eye 结果字段 → AI-VULN 统一 finding 结构（severity 大写）

关键设计：

  • 结果统一为 {scan_type, category, title, severity, detail, evidence, url, parameter, payload, remediation}。
  • severity 映射：critical→CRITICAL, high→HIGH, medium→MEDIUM, low→LOW, info→INFO。
  • 默认 verify=False（与 web_scanner.py 一致，自签名/内部证书场景），现已改为可配置，生产环境可传 verify=True。

3.2 web_scanner.py（修改）

  • 顶部新增 from web_vuln_scanner import WebVulnScanner。

  • scan() 新增 do_active: bool = True 参数；结果字典新增 active 键；在 ZAP 之后追加主动检测阶段。
  • _aggregate_findings() 将 result['active'] 并入 findings。
  • _persist() 写入新增的 parameter/payload 字段，并保留 scan_type。

六、安全评审说明

自动化安全评审提出两点，处理如下：

  1. SSRF —— 不适用。WebVulnScanner 本身是 SSRF 检测器（主动发送 169.254.169.254 等探测 payload），且作为本地化部署的扫描器必须能访问内网/回环/RFC1918 目标。目标地址由运维人员指定，POST /api/webscan 已做角色门控（admin/analyst）。该「拉取任意 URL」行为在 web_scanner.py 中早已存在，非本次新增。
  2. TLS verify=False —— 已改为可配置：SafeHTTPClient / WebVulnScanner 新增 verify 参数（默认 False，与 web_scanner.py 一致），生产环境可传 verify=True 或注入 CA。

七、使用方式

# 独立引擎
from web_vuln_scanner import WebVulnScanner
findings = WebVulnScanner(verify=True).scan('https://target.example')

# 完整 Web 扫描（被动 + 主动）
from web_scanner import WebSecurityScanner
result = WebSecurityScanner(db=db).scan('https://target.example', do_active=True)
# REST API
curl -X POST http://127.0.0.1:8000/api/webscan \
  -H "X-API-Key: <key>" -H "Content-Type: application/json" \
  -d '{"target_url":"https://target.example","do_active":true}'

八、影响范围与回滚

  • 影响面：仅 Web 扫描链路（web_scanner.py + REST API + web_scan_results 表）；不触碰网络扫描、代码审计、CVE/0day、报告等既有模块。
  • 兼容性：do_active 默认 True 但为可选字段；do_active=False 时行为与改动前完全一致；ALTER TABLE 幂等，旧库无感。
  • 回滚：删除 web_vuln_scanner.py + tests/test_web_vuln_scanner.py，git checkout -- web_scanner.py database.py api/models/__init__.py api/routers/webscan.py 即可恢复。
