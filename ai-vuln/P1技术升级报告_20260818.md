## 二、改进1：Web 应用安全扫描

新增 `web_scanner.py`，四个子模块 + 编排器：

| 模块 | 功能 | 关键实现 |
|------|------|----------|
| `WebFingerprinter` | CMS/框架/中间件指纹识别 | 40+ 特征库（响应头 + 响应体），版本提取 + 置信度 + 去重 |
| `HTTPProber` | 自定义 HTTP 请求探测 | 任意 method/headers/body + 10 条内建高危路径（`/.git/config`、`/.env`、`/actuator/env`） |
| `DirectoryEnumerator` | 目录枚举 + 备份文件检测 | 33 词表 + 16 种备份后缀，并发受控（10 线程） |
| `ZAPScanner` | OWASP ZAP 被动扫描 | REST API 对接（零新 pip 依赖），未启动优雅降级 `available:false` |
| `WebSecurityScanner` | 编排器 | 指纹 → 高危路径 → 目录枚举 → ZAP，结果持久化 |

## 三、改进2：P1 核心能力补齐

### 3.1 弱口令检测（`weak_password_scanner.py`）
- 协议 handler：HTTP Basic / FTP / SSH（可选 paramiko），复用 `threat_intel.db` 弱口令字典。
- 不支持协议如实返回原因，不静默；命中即停；默认限速。

### 3.2 漏洞处置工作流（`workflow.py`）
- 9 状态状态机：`OPEN → CONFIRMED → IN_PROGRESS → FIXED → VERIFIED → CLOSED`，含 `FALSE_POSITIVE`/`DUPLICATE` 终态与 `REOPENED` 回退。
- 非法流转被拒绝；`assignee`/`note`/`reopen_reason` 全链路审计。

### 3.3 用户 + RBAC（`auth_rbac.py`）
- 密码哈希 `pbkdf2_hmac`（10 万次迭代 + 随机盐）；HMAC-SHA256 签名 token（零第三方依赖）。
- 4 角色权限矩阵（admin/analyst/auditor/viewer）+ `require_role` 依赖。
- 默认 `admin/admin123` 首次登录强制改密（服务端强制 + 前端改密界面）。

### 3.4 React Web 前端
- 登录 / 仪表盘 / 资产 / 扫描 / Web 扫描 / 弱口令 / 处置 / 用户 7 页面，Bearer token 多用户访问。
- 资产支持网址字段，可一键跳转 Web 扫描。

## 五、质量加固

### 5.3 安全审查修复（7 项）

## 六、工程化增强
