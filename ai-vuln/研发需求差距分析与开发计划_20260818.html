四、功能模块差距详细分析（FR-01 ~ FR-17，代码核实）

FR-01 资产管理（~45%）

  • ✅ 资产发现（nmap CIDR/IP 范围展开，纯 Python ipaddress）、CRUD、类型/重要性/OS 下拉、url 字段（对接 Web 扫描）。
  • ❌ 仍缺：批量 CSV/Excel 导入、标签系统、6 阶段生命周期状态机、树状结构（组织→部门→网络→子网→资产）。

FR-02/03 扫描策略与任务（~40%）

  • ✅ 扫描类型（quick/full）、任务创建/状态/进度/停止、scan_policies 表。
  • ❌ 仍缺：插件体系、策略模板/版本管理、定时调度、优先级调度、暂停/恢复、分布式执行。

FR-04 漏洞管理（~55%）

  • ✅ CVE 库（分页/搜索/CVSS 筛选）、vuln_dispositions 表 + workflow.py 状态机（本轮新增）、scan_results/web_scan_results 存储。
  • ❌ 仍缺：漏洞相似度去重、evidence/remediation 结构化展示。

FR-05 风险分析（~60%）

  • ✅ AI 批量核验（置信度/风险重评/KEV 加权）、CVSS、generate_ai_analysis 报告。
  • ❌ 仍缺：多因子风险评分（资产价值×威胁×脆弱性）、EPSS 融合评分。

FR-06 修复管理（~25%）

  • ✅ AI 生成修复建议（ai_remediation）。
  • ❌ 仍缺：可执行修复脚本、工单集成（Jira/ServiceNow/钉钉/飞书，全库 grep 无结果）、复测验证闭环。

FR-07 报告中心（~50%）

  • ✅ HTML/MD/TXT + PDF(weasyprint)/Word(docx)（本轮已具备，含 HTML 回退降级）。
  • ❌ 仍缺：5 类预定义模板、定时分发、图表导出完善。

FR-08 系统管理（~55%）

  • ✅ 用户 CRUD + 角色 + 审计日志（audit_logs 表 + add_audit_log）——本轮新增。
  • ❌ 仍缺：配置中心、组织管理、MFA、令牌吊销（见第八节缺陷 #1）。

FR-09 API 接口（~65%）

  • ✅ REST：/api/v1/{assets,scans,cve,intel,audit,reports,dashboard,auth,users,webscan,weakpass,workflow}，Swagger /api/docs，API Key + Bearer 双认证。
  • ❌ 仍缺：GraphQL、Webhook、开放 SDK 文档、API 限流。

FR-10 插件管理（~0%）

❌ 完全缺失：插件 SDK/上传/版本/热加载/沙箱。

FR-11 多类型扫描（~20%）

  • ✅ 通用 OS + 端口 + Web 应用扫描（本轮新增）。
  • ❌ 仍缺：网络设备、安全设备、IoT、工控、国产化（麒麟/统信/达梦等）专项检测。

FR-12 大数据组件扫描（~10%）

❌ 仅端口层面识别，无 Hadoop/ES/Kafka/ClickHouse 等深度漏洞检测。

FR-13 弱口令检测（~40%）

  • ✅ HTTP Basic / FTP / SSH（paramiko 可选）+ 字典库——本轮新增。
  • ❌ 仍缺：MySQL/PostgreSQL/Redis/MongoDB/RDP/Telnet（代码如实返回"暂不支持"），无分布式字典、无锁定策略规避。

FR-14 漏洞库规则（~60%）

  • ✅ NVD 同步框架 + CWE/补丁链接回填 + 去重 + FAKE 清理。
  • ❌ 仍缺：450K+ 规模扩充、增量实时同步、供应商公告自动化。

FR-15 资产管理增强（~20%）

❌ 树状结构、服务/Web/漏洞/历史多维详情未完整实现。

FR-16 自动化漏洞验证（~35%）

  • ✅ AI 辅助验证（AIScanEnhancer/AIVerifier）。
  • ❌ 仍缺：PoC 安全执行沙箱、复测自动验证。

FR-17 隐匿站点探测（~25%）

  • ✅ 端口服务识别 + Web 指纹 + 目录枚举（本轮新增）。
  • ❌ 仍缺：暴露面综合分析报告、暗网/深网监测。
