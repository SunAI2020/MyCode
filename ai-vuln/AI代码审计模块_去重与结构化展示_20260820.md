## 一、概述

在上一轮「代码质量/设计审计」增强基础上，本轮为 AI 代码审计模块补齐两项能力：

1. **漏洞相似度去重**：安全扫描、确定性规则、AI 深度分析多来源发现合并后，同一文件同一维度同一类别的重复/高度相似发现只保留一条。
2. **evidence/remediation 结构化展示**：每条发现统一产出结构化「证据（evidence）」与「修复方案（remediation）」，供报告、GUI、数据库统一消费。

同时修复用户反馈的缺陷：勾选「深度代码质量/设计审计」后，点击「停止AI审计」无法中断后续质量审计。

## 二、相似度去重（新增 `audit_dedup.py`）

### 去重策略

| 项目 | 说明 |
|---|---|
| 指纹 `fingerprint` | `(file, dimension, category)` |
| 相似度 `similarity` | 同指纹下：行号相同 → 1.0；代码 `difflib.SequenceMatcher` 相似度 ≥0.6 → 返回该值；行号相邻 → 0.7 兜底 |
| 阈值 | `SIMILARITY_THRESHOLD = 0.85`（保守，仅高相似度判重，避免误删独立问题） |
| 保留优先级 | 严重度（CRITICAL>HIGH>MEDIUM>LOW>INFO）> 信息完整度（problem+recommendation 长度） |

### 关键 API

| 函数/类 | 说明 |
|---|---|
| `fingerprint(finding)` | 去重指纹 |
| `similarity(a, b)` | 两条发现相似度 0-1 |
| `AuditDeduplicator.deduplicate(findings)` | 返回 `{'unique': [...], 'duplicates': [...]}` |

## 三、evidence/remediation 结构化（新增 `audit_enrich.py`）

### 结构化证据 evidence

```json
{
  "file": "a.py", "line": 10,
  "dimension": "函数规范", "category": "函数过长",
  "severity": "MEDIUM", "code": "def foo():",
  "problem": "职责过多",
  "summary": "a.py:10 处发现【函数规范·函数过长】问题"
}
```

### 结构化修复方案 remediation

```json
{
  "summary": "按单一职责拆分…",
  "steps": ["步骤1", "步骤2", "…"],
  "source": "ai | rule | generic",
  "urgency": "立即修复 | 紧急修复 | 计划修复 | 排期修复 | 建议优化"
}
```

- **source 判定**：`ai`（AI 深度分析 / AI 核验的 `ai_fix_suggestion`）> `rule`（正则规则 / 确定性规则）> `generic`（无方案回退）。
- **steps**：修复建议按中文分号/句号/换行拆分为步骤列表。

### 关键 API

| 函数 | 说明 |
|---|---|
| `build_evidence(finding)` | 生成结构化证据 |
| `build_remediation(finding)` | 生成结构化修复方案 |
| `enrich_audit_findings(findings)` | 批量富化（evidence 缺失时填充，remediation 每次重算） |
| `evidence_dict(finding)` / `remediation_dict(finding)` | 安全获取结构化字段，兼容 DB 反序列化 |

## 六、修复：停止按钮无法中断质量审计

**问题**：勾选「深度代码质量/设计审计」后，点击「停止AI审计」不影响后续质量审计。

**根因**：`QThread.requestInterruption()` 只设置中断标志，但质量审计的目录遍历/AI 分块循环从未检查该标志，只能依赖 5 秒超时后的 `terminate()`（不可靠、易遗留子进程）。

**修复**：建立 `should_stop` 回调链，在每文件、每分块前检查中断：

```
AIAuditThread.isInterruptionRequested
  → scan_directory(should_stop=…)
    → AICodeReviewer.review_project(should_stop=…)
      → _run_ai_review(should_stop=…)
```

点击停止后，质量审计会在下一文件/分块边界**优雅中止**并返回已完成的发现。
