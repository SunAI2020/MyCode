一、目标与范围

本次升级在 P0（测试体系 + FastAPI API 层 + 双后端配置）基础上，聚焦两大方向：

编号方向内容优先级
改进1Web 应用安全扫描OWASP ZAP 被动扫描、自定义 HTTP 探测、Web 指纹识别、目录枚举 + 备份文件检测核心
改进2P1 核心能力补齐弱口令检测、漏洞处置工作流、用户+RBAC、React Web 前端核心

设计原则

  1. 保守安全：ZAP 不可用 / 探测失败 → 明确降级为内置引擎，绝不丢真实漏洞。
  2. 零强依赖：核心功能用标准库 + 已装依赖实现，paramiko/zaproxy 为可选增强。
  3. 数据主权：前端 SPA 由 FastAPI 本地托管，无 CDN 外链。
  4. 线程安全：所有新扫描模块支持 progress_callback。
  5. 测试先行：每个新模块配 pytest 用例，零回归。

二、改进1：Web 应用安全扫描

2.1 模块架构

web_scanner.py
  ├── WebFingerprinter      # Web 指纹识别（CMS/框架/中间件）
  ├── HTTPProber            # 自定义 HTTP 请求探测
  ├── DirectoryEnumerator   # 目录枚举 + 备份文件检测
  ├── ZAPScanner            # OWASP ZAP 被动扫描（REST API，可选）
  └── WebSecurityScanner    # 编排：指纹 → 探测 → 目录 → ZAP

2.2 Web 指纹识别

  • 中间件：Server/X-Powered-By/X-AspNet-Version 响应头 → nginx/apache/IIS/Tomcat 等。
  • CMS/框架：响应体特征库（wp-content/wp-json → WordPress；__VIEWSTATE → ASP.NET；csrfmiddlewaretoken → Django 等）。
  • 版本提取：正则匹配 Server: Apache/2.4.49、X-AspNet-Version: 4.0。
  • 输出：{product, category, version, confidence, evidence} 列表，对接既有 CVE 匹配。

2.3 自定义 HTTP 请求探测

支持自定义 method/headers/body/path/timeout/follow_redirects；返回 status/headers/body/preview/elapsed；内建高危路径探测（/.git/config、/.env、/actuator/env、/server-status）。

2.4 目录枚举 + 备份文件检测

内置目录词表（admin/backup/config/test/upload/logs 等）+ 备份后缀（.bak/.old/~/.swp/.sql/.zip/.tar.gz/.7z）；按状态码分类命中；并发受控（默认 10 线程）。

2.5 OWASP ZAP 被动扫描

通过 ZAP REST API（http://127.0.0.1:8080/JSON/...）对接，零新 pip 依赖；流程 context → openUrl → spider → passiveScan → alerts；ZAP 未启动 → 优雅降级返回 available:false。

三、改进2：P1 核心能力补齐

3.1 弱口令检测模块

组件说明
WeakPasswordScanner编排器：按协议分发到 handler，聚合结果
HTTPBasicAuthHandlerHTTP Basic 认证爆破（标准库）
FTPHandlerFTP 登录（ftplib）
SSHHandlerSSH 登录（paramiko，可选）
GenericSocketHandler通用 TCP banner/响应比对

字典来源复用 threat_intel.db 的 weak_passwords 表；作为扫描流水线独立阶段；默认限速 + 明确授权提醒。

3.2 漏洞处置工作流

                  ┌────────────── FALSE_POSITIVE (终态)
                  │
OPEN ──► CONFIRMED ──► IN_PROGRESS ──► FIXED ──► VERIFIED ──► CLOSED (终态)
  │                         │            │
  └────── DUPLICATE (终态)   └──► REOPENED（回退）

非法流转被状态机拒绝；记录 assignee/note/reopen_reason + 全链路时间戳审计。

3.3 用户 + RBAC 系统

  • 密码哈希：hashlib.pbkdf2_hmac（10 万次迭代 + 随机盐）。
  • 会话令牌：HMAC-SHA256 签名 token，带过期时间与角色声明。
  • 角色：admin（全权）/ analyst / auditor / viewer。
  • RBAC 依赖：FastAPI require_role(...) 装饰式授权。
  • 默认账号：admin / admin123（首次登录强制修改）。

3.4 React Web 前端

React 18（本地静态资源）+ 原生 Fetch + 无构建步骤，FastAPI StaticFiles 托管；页面：登录/仪表盘/资产/扫描/Web 扫描/弱口令/处置/用户/CVE；token 存 localStorage；预留 Vite 迁移路径。

六、风险与缓解

风险影响缓解
ZAP 未部署被动扫描缺失优雅降级到内置引擎
弱口令爆破影响生产业务中断低并发 + 限速 + 授权提醒
新增表破坏既有库回归CREATE TABLE IF NOT EXISTS
token 泄露越权HMAC 签名 + 过期 + 审计日志

七、验收标准

  • pytest tests/ -v 全部通过（含新增 4 个测试文件）
  • python api_server.py 启动，/api/docs 可访问
  • /api/v1/auth/login 成功返回 token；未授权访问被拒
  • /api/v1/webscan 返回指纹 + 目录枚举结果（ZAP 可选降级）
  • /api/v1/weakpass 复用弱口令字典执行检测
  • /api/v1/workflow 状态机拒绝非法流转
  • React 前端 / 可登录并访问仪表盘（多用户）
  • 既有 GUI / 既有 API 功能零回归
