AI-VULN 系统升级与功能增强说明

项目：下一代智能漏洞扫描系统 Pro（AI-VULN）2.1.0 组织：山西有信网安科技有限公司
日期：2026-08-30 范围：近两日软件升级、代码改动与功能增强汇总

一、概述

本次升级对标国际主流漏洞扫描系统（Nessus / Qualys / OpenVAS / Burp / Invicti / Wiz）， 以「借思路自建、复用现有引擎」的方式，补齐三项核心能力与两项工程增强， 并修复代码审查与安全审查发现的缺陷。核心诉求是：不引入闭源依赖或重量级外部系统， 把竞品的差异化能力（认证扫描、确定性验证、可达性优先、蜜罐识别）落到现有架构上。

二、功能增强

1. 蜜罐识别模块（新文件 honeypot_detector.py）

  • 能力：签名匹配（Cowrie / Conpot / Glastopf / Dionaea / OpenCanary）+ 服务组合异常（Honeyd / OpenCanary / T-Pot）
  • 原则：识别 → 标记 → 提示（不阻断）；P0/P1 强信号才标记，P2 弱信号只记证据供 AI 二次判断
  • 集成：scanner_engine.py 的 VulnScanner._detect_honeypots()

2. 认证扫描（新文件 credentialed_scan.py）

  • 能力：用已知凭证登录主机（SSH/WinRM），枚举已装软件包（rpm/dpkg/注册表），匹配 CVE
  • 定位：补「补丁缺失」类漏洞（对标 Nessus/OpenVAS credentialed scan，对 20% 覆盖率缺口）
  • 安全：主机密钥校验 + WinRM 仅 HTTPS + 证书校验，无降级路径

3. proof-based 证据验证（新文件 proof_verifier.py）

  • 能力：布尔盲注差分 + XSS 唯一 token 未编码回显验证
  • 定位：与 AI 核验互补（对标 Invicti）——AI 判语义误报，proof 给确定性证据
  • 集成：web_vuln_scanner.py 的 SQLi/XSS 检测

4. 暴露面系数（risk_scoring.py 升级）

  • 公式：资产价值 × 威胁(KEV/EPSS) × 脆弱性(CVSS) × 暴露面(可达性×网络暴露)
  • 对标 Wiz：公网 1.0 > 内网 0.7 > 回环 0.3，关闭端口 0.1；默认 1.0 不惩罚

5. 蜜罐徽标列（main_window.py + report_generator.py）

  • 结果表与 HTML 报告加「蜜罐」徽标列，命中显示紫色「🍯 蜜罐」
  • 双重判定：finding_type 或 description 前缀 [蜜罐告警]
