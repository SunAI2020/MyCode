## 一、概述

原 AI 代码审计模块（`ai_analyzer.py` + `ai_verifier.py`）**只做安全漏洞检测**：10 类正则（SQL 注入/命令注入/XSS/路径遍历/硬编码密钥/反序列化/弱加密/随机数/信息泄露/SSRF）+ 可选 Claude 误报核验，**不审查**软件设计架构、逻辑、函数规范、接口、API、数据库等设计质量问题。

本次增强使审计模块覆盖**安全 + 代码质量/设计**两个维度，对每个问题给出**详尽的解决方案**。

### 设计决策

1. **独立开关、可叠加**：保留现有「Claude Code Security」安全审计复选框，新增「深度代码质量/设计审计」复选框，两者可独立或同时运行，结果合并到同一报告。
2. **混合检测**：简单问题用**确定性规则**（免费、零延迟、无外部依赖）；复杂问题交给 **Claude AI** 深度分析。

## 三、分层检测设计

### 第一层：确定性启发式规则（免费、零依赖）

| 规则 | 触发条件 | 严重度 | 维度 |
|---|---|---|---|
| 循环嵌套过深 | `for`/`while` 嵌套 > 3 层 | MEDIUM | loop |
| 待办占位 | TODO/FIXME/XXX/HACK | LOW | completeness |
| 空实现占位 | 独立 `pass` 语句 | LOW | completeness |
| 未实现异常 | `raise NotImplementedError` | MEDIUM | completeness |
| 裸 except 捕获 | `except:` 无异常类型 | MEDIUM | function |
| 可变默认参数 | `def f(x=[]/{}/dict()/set()/list())` | MEDIUM | parameter |
| 函数过长 | 函数体 > 60 行 | MEDIUM | function |
| 命名不规范 | Python camelCase 变量/函数名 | LOW | naming |

### 第二层：Claude AI 深度分析

- 详细系统提示词 `CODE_REVIEW_SYSTEM_PROMPT`，从 14 个维度审查，仅报告真实、可行动问题。
- 每个问题返回 JSON：`{dimension, category, severity, line, code, problem, solution}`，`problem`/`solution` 为**详尽中文描述**（solution 含修复代码示例）。
- **分块**：单文件 > 400 行按行分块（重叠 10 行），避免 token 溢出。
- **文件准入**：跳过 > 200KB、二进制、压缩文件、`node_modules/__pycache__/venv/.git` 等目录。
- **失败保守**：AI 调用失败/解析失败 → 记录日志、跳过该文件，不产生空壳条目。

## 四、统一 issue 字段（安全与质量共用）

每个 issue（安全类 + 质量类）统一包含以下字段，展示/入库只需一套逻辑：

```json
{
  "file": "路径",
  "line": 行号,
  "dimension": "维度 key",
  "category": "问题类别",
  "severity": "CRITICAL|HIGH|MEDIUM|LOW|INFO",
  "code": "代码片段",
  "problem": "问题描述",
  "recommendation": "详尽解决方案"
}
```

安全类 issue 由 `_analyze_lines()` 补齐 `dimension='security'`、`problem`；质量类由 `AICodeReviewer` 产出。

## 六、使用说明

1. 启动 GUI：`python main.py` → 打开「AI代码审计」页。
2. 选择代码文件或目录。
3. 勾选「深度代码质量/设计审计」复选框（与「Claude Code Security」可独立/同时勾选）。
4. 点击「开始审计」，结果合并显示在 8 列表格中，自动生成 HTML + MD 报告。

**成本说明**：质量审计是可选、昂贵的 AI 操作，默认关闭；确定性规则在无 Claude CLI 时仍正常工作。
