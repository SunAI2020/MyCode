2.2 SAD 核心设计

  • 架构风格：微服务（资产/扫描/漏洞/报告/AI/情报/通知/认证 8 服务）
  • 技术栈：Go/Gin + Python/FastAPI + React/Vue + PostgreSQL + Redis + ES + Kafka + MinIO + K8s
  • 插件体系：Plugin SDK（scan/verify/remediate）+ 沙箱 + 版本管理
  • 数据架构：UUID 主键 / JSONB / 树状资产 / 多租户隔离
  • 部署：K8s HA + 边缘扫描节点（数据不出域）
  • 安全：纵深防御 5 层（WAF→MFA→RBAC/ABAC→TLS/AES→审计）
