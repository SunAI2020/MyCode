## 0. 目标与设计原则

| 原则 | 说明 |
|------|------|
| **识别 → 标记 → 提示**（不阻断） | 命中蜜罐只打标，不静默掉线，扫描继续 |
| **纯数据识别可测试** | 对齐 `DeviceFingerprinter.identify_host` 的"无网络 IO"设计 |
| **保守不误伤** | 仅 P0/P1 强信号标记 `is_honeypot=True`，P2 弱信号只记 evidence 供 AI 二次判断 |
| **零侵入复用 findings** | 蜜罐发现复用现有漏洞 dict 结构，报告/结果表免改 |

## 1. 模块架构（新建 `honeypot_detector.py`）

镜像 `device_fingerprint.py` 的四段式结构：

```
honeypot_detector.py
├── HONEYPOT_SIGNATURES        # 横幅/端口/Web 签名库（第一代）
├── HONEYPOT_PORT_SIGNATURES   # 端口组合异常（服务组合"过于齐全"）
├── class HoneypotDetector
│   ├── detect_host()           # 纯数据识别（无 IO，可测试）
│   ├── detect_tcp_behavior()   # 第三代：握手/时序异常（预留，默认关）
│   ├── _build_result()         # 信号聚合 + 置信度择优
│   └── detect_scan_result()    # 批量识别，回写 host_info['honeypot']
└── generate_honeypot_findings() # 生成对齐 vuln 结构的发现
```

## 2. 签名库设计（第一代）

每条签名含 `honeypot / protocol / field / pattern / confidence`，与 `device_fingerprint.BANNER_SIGNATURES` 同构，置信度对齐 `intel_sources` 的 P0/P1/P2 约定：

```python
HONEYPOT_SIGNATURES = [
    # Cowrie（SSH 蜜罐，默认 banner）
    {'honeypot': 'Cowrie', 'protocol': 'ssh', 'field': 'banner',
     'pattern': r'SSH-2\.0-OpenSSH_6\.0p1 Debian-4\+deb7u2', 'confidence': 'P1'},
    # Conpot（ICS/SCADA 蜜罐，默认 Web 页）
    {'honeypot': 'Conpot', 'protocol': 'http', 'field': 'http_title',
     'pattern': r'(?i)conpot|simatic s7-1200|siemens cp', 'confidence': 'P1'},
    # Glastopf / Dionaea / OpenCanary …（P2 弱信号）
]
```

> **来源诚实声明**：完整 18 类签名（Cowrie/Kippo/Dionaea/Conpot/Glastopf/Elastichoney/Honeyd/HoneyTrap/OpenCanary/T-Pot 等）与多步 hex/string/regex 匹配，应从 honeydet 与 Nuclei 的公开签名库移植。当前给出结构示例 + 常见高置信签名。

## 3. 集成改动（`scanner_engine.py`）

在 `VulnScanner.scan_target` 中，紧跟 `_identify_devices` 之后加一步：

```python
# 蜜罐/欺骗资产识别（识别→标记→提示，不阻断扫描）
honeypots, honeypot_findings = self._detect_honeypots(scan_result)
vulnerabilities.extend(honeypot_findings)
```

新增方法 `_detect_honeypots()`，返回 dict 新增 `honeypots` / `honeypot_count` 两键。

## 7. 风险与保守护栏

- **误报控制**：`is_honeypot=True` 仅限 P0/P1；P2 只记录 evidence，交给 `ai_scan_enhancer` 二次判断。
- **不阻断扫描**：命中蜜罐继续扫，符合"全面扫描 + 提示"定位。
- **签名维护**：`HONEYPOT_SIGNATURES` 作为静态情报源，可接入 `threat_intel.py` 定期更新。
