步骤八：问题整改闭环

问题发现 → 多轮整改 → 效果验证（阶段三 · FR-10）

1. 表（3 张）

表关键字段
issue 问题work_order_id, type, level, description, attachments, similar_ids, status
rectification 整改issue_id, plan, deadline, assignee, status
rectification_record 整改记录rectification_id, round_no, action, executor, effect

2. 状态机

  • 整改 status：整改中 → 已通过；不通过/部分完成自动下一轮。
  • 效果三态：通过 / 不通过 / 部分完成。
  • 问题 status：待整改 → 整改中 → 已关闭（全部整改通过）。

3. API

POST /work-orders/{id}/issues
GET/PUT/DELETE /issues[/{id}]
POST /issues/{id}/rectifications
GET/PUT /rectifications[/{id}]
POST /rectifications/{id}/rounds
GET /rectifications/{id}/records
