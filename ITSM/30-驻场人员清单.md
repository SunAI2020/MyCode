# 步骤三十：驻场人员清单（完善方案 P1 · §7.1）

> 依据：V7.0 · §7.1 驻场配置「驻场人员：具体人员清单（可换岗）」· §18.2 onsite_assignment
> 范围：补 `OnsiteAssignment` 驻场人员清单模型 + 增删改查端点，支持换岗。

## 1. 目标

驻场配置从「仅人数（headcount）」升级为「人员清单」，可换岗：

1. `OnsiteAssignment` 模型（onsite_id/user_id/起止/状态）。
2. 挂接到驻场配置的人员增删改查端点。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `models/onsite.py` | `OnsiteAssignment` 模型 |
| `alembic/versions/0015_onsite_assignment.py` | 迁移 |
| `schemas/onsite.py` | `OnsiteAssignmentCreate/Update/Out` |
| `api/v1/onsite.py` | assignments 端点 |
| `router.py` | 注册 |
| `tests/test_onsite_assignment.py` | 回归测试 |

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/onsite-assignments?onsite_id=` | 某驻场配置人员清单 |
| POST | `/onsite-assignments` | 添加驻场人员 |
| PUT | `/onsite-assignments/{id}` | 换岗（状态/结束日期） |
| DELETE | `/onsite-assignments/{id}` | 移除 |
