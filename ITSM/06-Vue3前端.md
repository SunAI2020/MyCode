# 步骤六：Vue3 前端（布局 + 登录 + 核心页面接通后端）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §7 前端设计 / 三区布局
> 范围：登录鉴权 + 客户/合同(子项·CI)/工单(派单·状态)/SLA 页面接通 `/api/v1`。

## 1. 目标

在步骤一~五后端之上，落地 Vue3 前端：三区布局（顶栏 + 侧边导航 + 内容）、登录鉴权、核心业务页面 CRUD 与关键动作（创建工单、派单、状态流转、周期生成）。

## 2. 页面清单

| 页面 | 路由 | 功能 |
|---|---|---|
| 登录 | `/login` | `/auth/login` + 存 token/user |
| 仪表盘 | `/dashboard` | KPI 计数（客户/合同/工单） |
| 客户管理 | `/customers` | CRUD |
| 合同管理 | `/contracts` | 合同 CRUD + 子项 + CI 三 tab |
| 工单管理 | `/work-orders` | 列表 + 创建 + 派单 + 状态流转 |
| SLA/周期/提醒 | `/sla` | 三 tab（SLA CRUD + 周期/提醒只读） |

## 3. 技术要点

- axios 拦截器：注入 `Bearer`、`code!==0` 统一报错（脚手架已有）。
- 路由守卫：无 token 跳 `/login`。
- `stores/auth.ts`：token + user + roles，登录后 `fetchMe()` 拉取角色。
- 三区布局：`MainLayout` 顶栏 + 侧边菜单 + 内容。

## 4. 验证

```bash
cd frontend && npm install && npm run dev   # 5173
# admin/admin123 登录 → 依次跑通 客户→合同→子项→工单→派单→状态
```
