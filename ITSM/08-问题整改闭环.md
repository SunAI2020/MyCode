# 步骤八：问题整改闭环（阶段三 · FR-10）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §4.9 / §6.2
> 范围：问题发现 → 多轮整改 → 效果验证的闭环。

## 1. 目标

实现 `issue（问题）→ rectification（整改）→ rectification_record（整改记录）` 闭环：执行中发现安全问题，多轮整改，效果验证通过后归档。

## 2. 表（3 张，依据 §6.2）

| 表 | 关键字段 |
|---|---|
| `issue` 问题 | work_order_id, type, level, description, attachments, similar_ids, status |
| `rectification` 整改 | issue_id, plan, deadline, assignee, status |
| `rectification_record` 整改记录 | rectification_id, round_no, action, executor, effect |

## 3. 状态机

- 整改 `status`：`整改中 → 已通过`（效果=通过）；`整改中`（效果=不通过/部分完成，自动下一轮）。
- 效果三态：`通过 / 不通过 / 部分完成`。
- 问题 `status`：`待整改 → 整改中 → 已关闭`（该问题下所有整改均已通过）。

## 4. API

- `POST /work-orders/{id}/issues` 记录问题
- `GET/PUT/DELETE /issues[/{id}]`
- `POST /issues/{id}/rectifications` 创建整改
- `GET/PUT /rectifications[/{id}]`
- `POST /rectifications/{id}/rounds` 提交整改轮次（效果验证）
- `GET /rectifications/{id}/records` 整改记录
