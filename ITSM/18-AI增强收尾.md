# 步骤十八：AI 增强收尾（阶段五 · FR-17 收尾）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §4.16
> 范围：统一 LLM 抽象层复用 + 工单摘要 + 工单转知识草稿 + ES 冷启动索引回填。

## 1. 目标

补齐阶段五 AI/检索收尾能力（均遵循 §4.16「建议 + 人工确认」，LLM 不可用时确定性降级）：

- **LLM 抽象层复用**：抽取 `rag_service` 内的 LLM 调用为共享 `llm_service`（DRY）。
- **工单摘要**：`POST /work-orders/{id}/summary` 自动生成执行摘要（LLM，无密钥降级模板摘要）。
- **工单转知识**：`POST /work-orders/{id}/to-kb` 将工单沉淀为知识草稿（status=草稿，待审核入库）。
- **ES 冷启动回填**：`POST /kb-articles/reindex` 全量索引已发布条目（ES 不可用返回 0）。

## 2. 文件清单

- `app/services/llm_service.py` — 统一 LLM 抽象（`llm_configured` / `chat`）
- `app/services/rag_service.py` — 改用 `llm_service`
- `app/services/ai_service.py` — 工单摘要 / 工单转知识草稿
- `app/services/search_service.py` — 增 `reindex_kb`
- `app/api/v1/work_orders.py` — `/{id}/summary`、`/{id}/to-kb`
- `app/api/v1/kb.py` — `/reindex`
- `tests/test_ai_service.py` — 单测

## 3. 业务规则

- **摘要**：LLM 配置时生成，否则/异常回退确定性模板（工单号/类型/描述/状态/进度）。
- **转知识**：生成 `KbArticle(status=草稿)`，作者取当前用户；草稿走既有知识库审核流程再发布。
- **回填**：仅索引 `status=已发布`；ES 未配置/未安装/不可达时静默返回 0。
