# ITSM 软件设计报告

> 项目：IT运维集中管控平台（ITSM）
> 版本：V1.0 · 依据《安全运维集中管控平台_完整交付文档》V7.0

---

## 一、项目概述

IT运维集中管控平台面向安服团队 / MSSP，以「合同 → 子项 → 工单」为主轴，统一承载客户合同履约、内部任务、外包协作、问题整改、交付、绩效、SLA 提醒、AI 增强与知识沉淀，形成可追溯、可量化、可考核、可自动化的完整交付闭环。

## 二、总体架构

### 3.2 ER 关系（核心）

```
customer 1—N contract 1—N contract_item 1—N service_cycle → 定期工单

work_order 1—N delivery

sla_policy → escalation（升级记录）
```

## 四、关键设计

### 4.1 七级 RBAC + 多租户隔离

- 8 角色（平台 5 + 客户 2 + 外包 1），`sys_user_role.customer_id` 做客户行级隔离锚点。
- `scope_filter` / `assert_scoped` / `owning_customer_id` 三层行级隔离。
- 字段级脱敏（`mask_sensitive`）：客户/外包侧电话、IP、金额遮蔽。
- 外包账号额外 `outsourcing_scope_of` 隔离（仅见被指派任务）。

### 4.2 可配置工作流引擎

- `DEFAULT_TRANSITIONS` 内置兜底 + `workflow_rule` DB 扩展 + `action_log` 全量留痕。
- `Approval` 审批流：申请 → 通过（自动流转）/ 拒绝，职责分离（不能自审自批）。

### 4.3 AI 增强（建议 + 人工确认）

- 摘要、工单转知识、智能分类、派单建议（技能矩阵）、合同履约洞察、RAG 问答。
- 统一 `llm_service`（urllib 调 OpenAI 兼容 API），未配置时确定性降级。

### 4.4 数据安全

- 脱敏（电话/IP/金额）、水印（前端用户名+日期）、审计（before/after+IP+时间）。
- 字段级加密：`EncryptedText`（Fernet AES）用于 `Outsourcing.nda`。
- 审计真实 IP：`TRUST_PROXY_HEADERS` 开关 + X-Real-IP。

### 4.5 周期拆分与 SLA

- `split_cycles`：按频率均匀拆分（2 次/周跨月不重复不遗漏）。
- `add_work_minutes`：工作日历跳过非工作时段。
- SLA 分级预警（红/橙/黄）+ 升级链 + `escalation` 记录。

## 五、部署架构

- 本地开发：docker compose（PG/Redis/ES）+ uvicorn + vite。
- 生产：docker compose prod（backend + nginx 前端 + 中间件），健康检查/依赖/卷。
- 云（阿里云）：RDS PG / 云 Redis / 云 ES / OSS / KMS / SLB / WAF / CDN（见 `41-阿里云部署方案.md`）。
- 一键安装：`install.bat/.sh` + `start.bat/.sh`。

## 六、非功能性设计

- **可测试性**：132 个 pytest 单测，覆盖核心算法/隔离/安全。
- **降级设计**：Redis→内存缓存、ES→SQL、LLM→规则/检索，未装中间件不影响核心功能。
- **可观测性**：统一响应/异常/审计，`/api/v1/health` 健康检查。
- **安全**：等保 2.0 三级对照（`security/等保三级对照.md`）、OWASP Top 10 清单。
