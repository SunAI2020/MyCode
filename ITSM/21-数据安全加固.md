# 步骤二十一：数据安全加固（阶段六 · FR-22）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §8.6 阶段六 · §5.3 数据安全
> 范围：审计 IP 留痕、字段级加密、前端水印、脱敏覆盖审查。

## 1. 目标

落地 FR-22「数据脱敏/加密/水印/审计」的在应用层可实施部分：

- **审计留痕补全**：`before/after + IP + 时间` 三要素齐备（时间已有 `operated_at`，本次补 IP）。
- **字段级加密**：敏感文本列（`Outsourcing.nda` 保密协议）AES 加密落库，可逆解密。
- **前端水印**：全屏「用户名 + 日期」水印防拍照泄露。
- **脱敏覆盖审查**：确认客户侧可见端点敏感字段已脱敏，无遗漏。

## 2. 文件清单

| 文件 | 变更 |
|---|---|
| `core/context.py` | 新增 `client_ip` ContextVar |
| `core/deps.py` | `get_current_user` 注入 `request`，捕获客户端 IP |

| `api/v1/outsourcing.py` | 外包审计 `after` 中 `nda` 脱敏 |
| `requirements.txt` | 补 `cryptography` |
| `frontend/src/layouts/MainLayout.vue` | 全局水印层 |
| `tests/test_crypto.py` / `tests/test_audit_ip.py` | 回归测试 |

## 3. 设计要点

- **加密**：`cryptography.fernet.Fernet`（AES-128-CBC + HMAC 认证），密钥由 `SECRET_KEY` 经 SHA-256 派生。密文带 `enc:v1:` 前缀，解密时非前缀值（历史明文）原样返回，实现无迁移平滑升级。
- **列类型**：`EncryptedText`（TypeDecorator，impl=Text）透明加解密，DB 列仍为 TEXT，无 DDL 变更。
- **IP 捕获**：`get_current_user` 覆盖全部鉴权端点，经 ContextVar 传递到 `record()`，线程安全。
