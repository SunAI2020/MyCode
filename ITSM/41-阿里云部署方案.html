步骤四十一：阿里云部署方案（完善方案 P2 · §21）

依据：V7.0 · §21 部署架构（阿里云）
范围：本地 docker 映射阿里云 + 迁移方案 + 安全配置。

1. 架构映射

本地 docker阿里云服务
frontend (nginx)SLB + CDN + WAF
backend (uvicorn)ECS / ACK
postgresRDS PostgreSQL（高可用）
redis云数据库 Redis 版
elasticsearch阿里云 Elasticsearch
uploads/OSS + CDN（SSE）
—KMS + 安全组 + 云防火墙

2. 迁移步骤

数据层（RDS 导入 + SSL/TDE/备份加密）→ 对象存储（OSS）→ 缓存/检索（云 Redis/ES）→ 应用层（ECS/ACK 复用镜像）→ 接入层（SLB/WAF/CDN + TLS）→ 安全（安全组/KMS/云防火墙）。

3. 数据安全

TLS 1.2+ 全链路；RDS TDE + OSS SSE + KMS 信封加密；应用层脱敏/水印/审计已落地。

4. 说明

本方案为迁移蓝图，本地 docker 已可演示全部能力；容器镜像与备份脚本已在步骤二十二交付。
