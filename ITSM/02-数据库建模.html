步骤二：数据库建模

SQLAlchemy 模型 + Alembic 迁移 + 种子数据 · MVP 18 张表

1. 目标

用 SQLAlchemy 2.0 建模 MVP 全量表，Alembic 生成初始迁移，seed.py 写入七级角色/权限/字典/管理员。

2. 表清单（18 张）

3. 模型文件结构

backend/app/models/
├── __init__.py     # 汇总导入所有模型，供 Alembic autogenerate 发现
├── system.py       # sys_user/role/permission/user_role/role_permission/audit_log/dict
├── customer.py     # customer
├── contract.py     # contract / cmdb_ci / contract_item
├── work_order.py   # work_order / order_receive / work_order_assignee
├── dispatch.py     # order_dispatch
└── service.py      # service_cycle / service_reminder / sla_policy

cd backend && .venv/Scripts/activate
