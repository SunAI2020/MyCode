# 步骤三十五：服务对象依赖拓扑（完善方案 P2 · FR-13）

> 依据：V7.0 · §3.1 服务对象「依赖关系（影响分析）」· FR-13 CMDB 增强
> 范围：`CmdbCiDependency` 依赖关系表 + 依赖管理 + 影响分析。

## 1. 目标

为 CMDB 服务对象建立依赖拓扑，支撑变更影响分析：

1. `CmdbCiDependency`（source 依赖 target）。
2. 添加/删除/列表依赖。
3. 影响分析：`GET /cmdb-cis/{id}/impact` 返回该 CI 故障时受影响的上游（递归）。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `models/contract.py` | `CmdbCiDependency` 模型 |
| `alembic/versions/0018_cmdb_dependency.py` | 迁移 |
| `schemas/cmdb.py` | 依赖 schema |
| `api/v1/contracts.py` | 依赖端点 + 影响分析 |
| `tests/test_cmdb_dependency.py` | 回归测试 |

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/cmdb-ci-dependencies` | 添加依赖 |
| GET | `/cmdb-cis/{id}/dependencies` | 该 CI 的依赖 |
| GET | `/cmdb-cis/{id}/impact` | 影响分析（递归上游） |
| DELETE | `/cmdb-ci-dependencies/{id}` | 删除 |
