步骤一：工程骨架与基础设施

依据《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §9.1 阶段一

1. 目标

跑通「本机可运行空壳系统」：PostgreSQL（Docker）→ FastAPI 后端（Swagger 可访问）→ Vue3 前端（登录页占位可访问），三者通过 .env + vite 代理串起来。

2. 交付物清单

文件作用
docker-compose.yml拉起 PostgreSQL 16，数据卷持久化，预留 Redis 注释位
.env.exampleDATABASE_URL / SECRET_KEY / 过期时间模板
README.md项目说明 + 一键启动步骤
backend/requirements.txtFastAPI 全家桶依赖
backend/app/main.py入口：路由挂载、CORS、健康检查、Swagger

backend/app/db/session.py / base.pySQLAlchemy engine / SessionLocal / Base
backend/app/utils/response.py统一响应 + 分页
frontend/Vite + Vue3 + Element Plus + Pinia + Router + Axios 脚手架

3. 技术要点

  • 后端：FastAPI + Uvicorn；pydantic-settings 读 .env；SQLAlchemy 2.0（psycopg 驱动）。
  • 统一响应契约（文档 §7.1）：/api/v1 前缀、{"code":0,"message":"ok","data":{}}、分页 ?page=&size=。
  • 前端：Vite 代理 /api → http://localhost:8000；axios 拦截器统一带 JWT、解析 code。

4. 验证方式

# 数据库
docker compose up -d
# 后端
cd backend && python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
# 打开 http://localhost:8000/docs 看 Swagger；GET /api/v1/health 返回 ok
# 前端
cd frontend && npm install && npm run dev
# 打开 http://localhost:5173 看登录页占位
