# 步骤二：数据库建模（SQLAlchemy 模型 + Alembic 迁移 + 种子数据）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §6.2 核心表清单 / §6.3 DDL
> 范围：MVP 所需的 18 张表（其余 issue/rectification/delivery/performance/onsite/outsourcing/change/kb 留到阶段三~五）。

## 1. 目标

用 SQLAlchemy 2.0 建模 MVP 全量表，Alembic 生成初始迁移，`seed.py` 写入七级角色/权限/字典/管理员，为步骤三 RBAC 与步骤四主干 API 打底。

## 2. 表清单（18 张）

| 域 | 表 | 关键字段 |
|---|---|---|
| 系统(RBAC) | `sys_user` | username, name, phone, dept, status, pwd_hash |
| | `sys_role` | code, name, scope[平台/客户] |
| | `sys_permission` | code, name, type[菜单/按钮/接口/字段] |
| | `sys_user_role` | user_id, role_id, customer_id（行级隔离锚点） |
| | `sys_role_permission` | role_id, permission_id |
| | `sys_audit_log` | user_id, action, resource, before, after, ip, operated_at |
| | `sys_dict` | category, code, name |
| 合同 | `customer` | name, industry, level, contact |
| | `contract` | customer_id, type, name, no, amount, start/end, has_onsite, status |
| | `cmdb_ci` | customer_id, name, type, ip, status, version, lifecycle |
| | `contract_item` | contract_id, ci_id, project, frequency, unit, sla_policy_id, accept_standard, price |
| 工单 | `order_receive` | source, customer_id, contract_id, contract_item_id, ci_id, project, contract_price, contact, service_start/end |
| | `order_dispatch` | work_order_id, dispatch_type, dispatch_price, service_start/end, suggest_reason |
| | `work_order` | no, type, receive_id, dispatch_id, contract_id, contract_item_id, ci_id, project, status, priority, sla_deadline, progress, current_cycle_no |
| | `work_order_assignee` | work_order_id, user_id, workload_ratio, actual_hours, started_at, ended_at, is_active |
| 服务 | `service_cycle` | contract_item_id, cycle_no, service_start, service_end, status, auto_generated（UNIQUE(contract_item_id, cycle_no)） |
| | `service_reminder` | cycle_id, type, level, content, to_user_id, channel, sent_at |
| | `sla_policy` | name, customer_level, response_limit, resolve_limit, work_calendar_id, escalation_chain |

## 3. 模型文件结构

```
backend/app/models/
├── __init__.py        # 汇总导入所有模型，供 Alembic autogenerate 发现
├── system.py          # sys_user/sys_role/sys_permission/sys_user_role/sys_role_permission/sys_audit_log/sys_dict
├── customer.py        # customer
├── contract.py        # contract / cmdb_ci / contract_item
├── work_order.py      # work_order / order_receive / work_order_assignee
├── dispatch.py        # order_dispatch
└── service.py         # service_cycle / service_reminder / sla_policy
```

## 4. 迁移与种子

- `alembic.ini` + `alembic/env.py`（读 `settings.DATABASE_URL`）+ `versions/0001_initial.py`。
- `app/db/seed.py`：
  - 7 角色（系统管理员/系统运维/工单管理/客服/安服 + 客户系统管理员/客户服务管理）
  - 字典枚举：运维项目 16 项、服务频率 7 项、工单状态 8 项、合同类型 6 项
  - 初始管理员 `admin`（bcrypt 密码）

## 5. 验证

```bash
cd backend && .venv/Scripts/activate
alembic upgrade head            # 建 18 张表
python -m app.db.seed           # 写入角色/字典/管理员
# psql 或 python 查询：sys_role 应有 7 行、sys_dict 应有 37 行
```
