2. 技术要点

  • axios 拦截器：注入 Bearer、code!==0 统一报错。
  • 路由守卫：无 token 跳 /login。
  • stores/auth.ts：token + user + roles。
  • 三区布局：MainLayout 顶栏 + 侧边菜单 + 内容。
