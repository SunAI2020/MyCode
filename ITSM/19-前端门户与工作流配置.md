# 步骤十九：前端自助门户 + 知识库 + 工作流配置（阶段五收尾）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §4.17 / §4.18
> 范围：Vue3 + Element Plus 落地三个页面，对接步骤十七/十八后端端点。

## 1. 目标

补齐阶段五前端：自助门户（概览 + 报障 + RAG 问答）、知识库（检索 + 增删 + RAG + ES 回填）、工作流配置（有效流转可视化 + 规则 CRUD）。

## 2. 文件清单

- `src/views/Portal.vue` — 门户概览 / 自助报障 / RAG 问答
- `src/views/Knowledge.vue` — 知识库列表检索 / 新增删除 / RAG / ES 回填
- `src/views/Workflows.vue` — 有效流转可视化 + 规则增改删/启停
- `src/api/index.ts` — 新增 portal / kb / workflow API 封装
- `src/router/index.ts` — 新增 /portal /knowledge /workflows 路由
- `src/layouts/MainLayout.vue` — 侧边导航新增三项

## 3. 验证

```bash
cd frontend && npm run build   # vue-tsc 类型检查 + vite 构建通过
```

## 4. 说明

- RAG 问答、ES 回填、工单转知识等前端交互对应后端「无 LLM/ES 时降级」语义，无需额外配置即可用。
- 三页面复用既有 `request`（统一响应拦截 + Bearer Token），与现有 CRUD 页风格一致。
