# 步骤三十三：AI 智能分类 + 派单建议（完善方案 P1 · §15）

> 依据：V7.0 · §15 AI 智能增强（智能分类 / 智能派单建议）
> 范围：技能矩阵 `EngineerSkill` + AI 分类 + 基于技能/负载/绩效的派单推荐。

## 1. 目标

1. `EngineerSkill` 技能矩阵模型（人员 × 运维项目 × 等级）。
2. `classify_ticket`：报障描述 → 推荐运维项目/优先级（LLM 可用则调 LLM，否则规则降级）。
3. `recommend_assignee`：按技能匹配（等级）→ 负载 → 绩效推荐执行人。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `models/engineer_skill.py` | `EngineerSkill` 模型 |
| `alembic/versions/0017_engineer_skill.py` | 迁移 |
| `schemas/ai.py` | 分类/技能 schema |
| `services/ai_service.py` | `classify_ticket` / `recommend_assignee` |
| `api/v1/ai.py` | 分类/推荐/技能 CRUD 端点 |
| `router.py` | 注册 |
| `tests/test_ai_dispatch.py` | 回归测试 |

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/ai/classify` | 描述 → 运维项目/优先级 |
| GET | `/ai/recommend-assignee?project=` | 推荐执行人 |
| GET/POST/DELETE | `/engineer-skills` | 技能矩阵管理 |

## 4. 降级策略

LLM 未配置时：分类走关键词规则；推荐走技能匹配（等级排序），不依赖外部服务。
