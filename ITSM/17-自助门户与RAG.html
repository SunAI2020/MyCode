步骤十七：客户侧自助门户 + RAG 问答（阶段五 · FR-19 / FR-17）

依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §4.16 / §4.18
范围：客户自助报障/概览 + 知识库 RAG 问答（可配置 LLM，无密钥降级检索）。

1. 目标

  • 自助门户：客户侧角色自助报障（建接单 + 工单）、一键概览合同履约/工单进度/交付报告；全程按 customer_scope_of 行级隔离。
  • RAG 问答：知识库检索 + 可配置大模型摘要；未配置密钥时降级为「检索片段」，绝不泄露未发布条目。

2. 改动

  • 表：work_order 新增 description（报障描述）——迁移 0010。
  • 配置：LLM_API_BASE/LLM_API_KEY/LLM_MODEL（可选）。
  • 后端：/portal/tickets、/portal/overview、/kb-articles/ask。

3. 业务规则

  • 报障：客户侧 customer_id 强制取本人 scope；平台侧须显式传。同时落 order_receive + work_order（待派单）。
  • 概览：返回本人客户合同、工单各状态计数、最近工单、最近交付（均 scope_filter）。
  • RAG：仅检索 status=已发布；LLM 配置时摘要，否则/异常返回检索片段（mode=retrieval）。

4. 文件清单

  • app/models/work_order.py、alembic/versions/0010_portal.py
  • app/core/config.py、app/schemas/portal.py、app/schemas/kb.py
  • app/services/rag_service.py、app/api/v1/portal.py、app/api/v1/kb.py、app/api/v1/router.py
  • tests/test_rag_service.py / tests/test_portal.py

5. API

  • POST /portal/tickets 自助报障
  • GET /portal/overview 门户概览
  • POST /kb-articles/ask RAG 问答

6. 角色

报障/概览/RAG：sys_admin / sys_ops / ticket_mgr / cust_admin / cust_service（客户侧行级隔离；RAG 仅返回已发布条目）。
