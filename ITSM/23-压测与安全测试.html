步骤二十三：性能压测 + 安全测试 + 等保测评（阶段六收尾）

依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §8.6 阶段六 · §9 · §10.2
范围：JMeter 压测脚本、OWASP ZAP 扫描清单、等保 2.0 三级对照表。

1. 目标

维度工具/产物验收标准
性能JMeter（perf/itsm-load.jmx）并发 500 稳定，P95 < 500ms
安全OWASP ZAP（security/owasp-zap-checklist.md）OWASP Top 10 全覆盖
等保对照表（security/等保三级对照.md）等保 2.0 三级逐项对应

2. 文件清单

  • perf/itsm-load.jmx — JMeter 压测脚本
  • perf/README.md — 压测运行说明 + 阈值
  • security/owasp-zap-checklist.md — ZAP 扫描配置 + OWASP Top 10
  • security/等保三级对照.md — 等保 2.0 三级对照表
  • backend/app/api/v1/auth.py — 登录审计 IP 复用共享 _client_ip

3. 压测场景（JMeter）

登录（提取 token）→ 工单/客户/合同列表、门户概览、知识库检索。线程组 500 并发、30s 爬坡、循环 2 次，目标 P95 < 500ms、错误率 0。

4. 安全测试（OWASP ZAP）

主动扫描目标：认证、RBAC 越权、行级隔离、IDOR、注入、脱敏、审计。关键断言：客户侧角色不得访问他人客户数据；敏感字段响应须脱敏；审计含 IP。

5. 等保三级对照

九大类（物理/网络/边界/计算/管理/制度/人员/建设/运维）逐项对照系统实现与证据，详见 security/等保三级对照.md。

6. 验证

cd backend && python -m pytest -q
# JMeter：jmeter -n -t perf/itsm-load.jmx
# ZAP：按 checklist 对 http://localhost:8080 扫描

7. 说明

本步骤交付脚本与对照文档（执行模板），需在部署环境落地运行；不替代真实压测/渗透执行记录。移动端单独开阶段。
