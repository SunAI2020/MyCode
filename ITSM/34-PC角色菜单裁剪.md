# 步骤三十四：PC 端按角色裁剪菜单（完善方案 P1 · §24.1）

> 依据：V7.0 · §24.1 六套 PC 界面对照（按七级 RBAC 角色裁剪）
> 范围：`MainLayout` 侧边菜单按 `auth.user.roles` 动态渲染。

## 1. 目标

菜单按当前用户角色裁剪，实现 §20 权限矩阵的「按角色裁剪菜单」：

- 定义菜单项 × 角色白名单。
- 非 `sys_admin` 用户仅显示其角色允许的菜单。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `frontend/src/layouts/MainLayout.vue` | 菜单动态渲染 |

## 3. 菜单矩阵

| 菜单 | 可见角色 |
|---|---|
| 仪表盘 | 平台 + 客户角色（除安服/外包） |
| 客户/合同管理 | sys_admin / ticket_mgr |
| 工单管理 | 平台 + 客户角色 |
| 自助门户 | 平台 + 客户角色 |
| 知识库 | 平台 + 客户角色 |
| 工作流 | sys_admin / ticket_mgr |
| SLA / 周期 | sys_admin / sys_ops / ticket_mgr |
