# 步骤三十八：多渠道消息推送（完善方案 P2 · §14.4）

> 依据：V7.0 · §14.4 提醒渠道「站内 / 移动推送 / 短信·企微·飞书·钉钉」
> 范围：企微/飞书/钉钉 webhook 发送函数 + 配置，未配置降级站内。

## 1. 目标

为提醒消息提供多渠道路由：

1. `notify_service.send_channel(channel, content)`：企微/飞书/钉钉 webhook 发送，失败静默降级。
2. `config` 增 `WECOM_WEBHOOK` / `FEISHU_WEBHOOK` / `DINGTALK_WEBHOOK`。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `services/notify_service.py` | webhook 发送 |
| `core/config.py` | webhook 配置 |
| `tests/test_notify_service.py` | 回归测试 |
