1项目概述

1.1 建设背景

公司面向多个客户提供安全服务与安全运维（MSS）。多客户、多项目、多人员、多工单场景下，工单散落、资产不清、巡检靠人工、风险无台账、整改验收链路不闭环、交付付款脱节、报告混乱、工作量难以量化。

1.2 建设目标

  • 客户 / 项目资产集中管理
  • 工单全生命周期闭环（18 类工单类型）
  • 风险发现 → 整改（多轮）→ 验收 → 归档全流程线上化
  • 工程师移动端巡检打卡（GPS + 拍照）
  • 工程师工作量量化统计
  • 交付 + 客户评价 + 验收 + 付款 + 结案归档一体化
  • 数据脱敏、加密传输、数字水印、防拍照防截屏

1.3 核心价值

  • 提升管理效率，减少人工台账与沟通成本
  • 风险与整改全程留痕，满足审计合规要求
  • 交付物标准化、可追溯、可量化，客户评价闭环
  • 工作量可统计，支持绩效与成本核算

3详细功能设计（十一大核心模块）

3.1 客户与项目管理

客户档案：名称、行业、联系人、合同、SLA、服务周期、对接人。

客户运维系统列表（资产清单）：系统名称、用途、IP/域名、部署位置、关联安全设备（FW/WAF/IDS/IPS/堡垒机/日志审计）、责任人（客户侧+我方侧）、状态（在运/停用/下架）。

项目管理：状态机 立项→进行中→交付→验收→付款→结案→归档。

3.2 工单管理模块（18 类工单）

工单类型（共 18 类）：

生产型：XX年第X次·漏洞扫描XX年第X次·渗透测试XX年第X次·应急演练XX年第X次·安全加固XX年第X次·安全培训XX年第X次·代码审计XX年第X次·基线核查XX年第X次·安全巡检XX年第X次·安全评估XX年第X次·应急处置XX年第X次·重保值守XX年第X次·攻防演练XX年第X次·安全防护XX年第X次·设备巡检XX年第X次·等级保护测评XX年第X次·故障排查

事件/管理型：变更申请整改督办

  • 状态流转：新建→已派发→处理中→待验证→已完成→已关闭
  • 字段：编号、客户、系统、类型、优先级、SLA 时限、处理人、耗时、处理记录
  • 支持关联：风险台账、整改记录、客户运维系统、交付记录

3.3 安全风险台账模块（核心）

9 大类风险：

  1. 高危漏洞
  2. 安全设备报警日志
  3. 安全设备 License 过期
  4. 僵木蠕病毒 / 勒索 / 挖矿感染
  5. 跨网段非法外联
  6. 弱口令
  7. 硬件设备故障
  8. 机房环境问题
  9. 服务器性能异常

记录字段：编号、客户、系统、类型、等级（高/中/低）、发现时间、发现方式、描述、附件、状态 待整改→整改中→整改完成→已验收→已关闭、关联整改/工单。

关键点：风险台账是「一屏看清所有客户安全态势」的核心，支持多维度筛选、统计与导出。

3.4 整改管理模块（多轮整改 + 三态效果）

风险发现 → 制定整改方案 → 实施整改 → 整改效果验证 → 验收签字 → 归档
                ↑________________________________________|
          （不通过 / 部分完成，继续整改 → 发起新一轮整改）
  • 整改方案：整改措施、时间节点、实施人员、需协调资源
  • 整改记录：每次整改的过程、措施、实施人、整改日期
  • 整改效果（三态）： 通过 不通过 部分完成，继续整改
    「不通过 / 部分完成」均自动发起新一轮整改，形成多轮整改链
  • 验收记录：验收人签字（电子签名/照片）、验收结论
  • 整改报告：自动汇总多轮整改产出报告

3.5 移动巡检打卡模块

  • 巡检任务下发（运维计划生成 → 推送指定人员）
  • GPS 定位打卡（定位偏差校验防作弊）
  • 拍照上传（水印：时间+定位+人员，多图）
  • 巡检项填写（模板逐项勾选）
  • 打卡记录（轨迹 + 考勤，可导出）
技术点：GPS 定位能力、照片水印防伪、离线暂存、联网补传。

3.6 交付管理模块（16 类交付 + 客户评价）

交付类型（16 类）：漏洞扫描、渗透测试、应急演练、安全加固、安全培训、代码审计、基线核查、安全巡检、安全评估、应急处置、重保值守、攻防演练、安全防护、设备巡检、等级保护测评、故障排查。

  • 交付名称：X 年第 X 次（如「2026 年第 3 次」）
  • 交付时间节点、交付报告（关联报告中心）
  • 客户评价：每项交付需客户签字确认（电子签名 + 评价内容 + 满意度）
新增：客户评价闭环 —— 每项工作交付均需客户签字确认与评价，作为验收与服务的证据链。

3.7 运维计划模块

  • 计划字段：时间节点、运维内容、负责人、实施方案、需协调资源
  • 计划类型：日常巡检、漏洞扫描、渗透测试、应急演练、安全培训等
  • 状态：待执行→执行中→已完成→已关闭；自动生成巡检任务/工单

3.8 应急预案模块

  • 预案库：按风险类型维护标准预案
  • 预案触发：关联风险事件
  • 应急演练（四件套）：演练计划、演练方案、演练记录、演练报告（关联交付）

3.9 报告中心模块

  • 按客户、项目维度归档所有报告
  • 分类：巡检/漏洞扫描/渗透测试/应急演练/安全评估/基线核查/等保测评/整改报告等
  • 在线预览、版本管理、下载、检索、模板化自动生成

3.10 工作量统计模块（新增）

按照各项工作类型，分别计算工程师工作量：

  • 统计维度：按人员、按客户、按工作类型、按时间（日/周/月/季/年）
  • 工作量来源：工单处理、巡检打卡、风险录入、整改实施、交付产出等自动归集
  • 量化口径：工单数、巡检次数、风险处理数、整改轮次、交付次数、投入工时
  • 产出：个人工作量报表、团队汇总、绩效与成本核算依据

3.11 验收 / 付款 / 结案归档

  • 验收记录：验收项、标准、验收人、结论、签字/盖章
  • 付款记录：节点、金额、发票、到账状态、收款确认
  • 结案归档：全量资料一键归档，生成结案档案，只读锁定

6安全与合规设计（新增重点）

6.1 数据脱敏处理

  • 敏感字段（IP、手机号、身份证、客户联系人、密码/口令等）展示与导出时自动脱敏（掩码/星号）
  • 支持按角色配置脱敏级别（完全可见 / 部分掩码 / 完全隐藏）
  • 日志与报告输出同样执行脱敏规则

6.2 全程加密传输

  • 全站 HTTPS/TLS 1.2+ 强制
  • 接口层数据加密，敏感数据存储加密（AES-256）+ 密钥分层管理
  • 文件 / 照片传输加密，对象存储服务端加密

6.3 数字水印（防泄露溯源）

  • 屏幕显示水印：页面叠加隐藏数字水印（用户 ID + 时间 + 会话），仅肉眼弱可见，可被程序识别用于泄露追踪
  • 打印件水印：打印输出嵌入隐藏数字水印，可追溯打印人、时间

6.4 防拍照 / 防截屏

  • 防截屏：检测截屏/录屏行为并告警（移动端），敏感页面置灰或警示
  • 防拍照：敏感页面叠加动态水印 + 屏显警示，配合移动端截屏检测
  • 关键操作（下载、导出、打印）均记录审计日志

8非功能性要求

  • 安全：HTTPS、数据脱敏、加密传输、数字水印、防拍照防截屏、操作审计
  • 可靠：数据备份、异常监控
  • 性能：大数据量检索（ES）
  • 可审计：关键操作全留痕
  • 移动友好：打卡离线暂存、弱网补传

9实施路线（分阶段）

阶段内容周期（估）
一期客户/项目/资产管理 + 工单(18类) + 风险台账 + 整改闭环(三态多轮)8-10 周
二期移动巡检打卡 + 运维计划 + 工作量统计4-6 周
三期交付管理(16类+客户评价) + 报告中心 + 应急预案(四件套)4-6 周
四期验收/付款/结案归档 + 客户门户 + 安全水印/防截屏/脱敏 + 数据看板4-6 周
MVP 建议：先做一期，覆盖「客户资产 → 工单 → 风险 → 整改」核心闭环，快速上线验证。

10补充建议

  • 风险台账 是灵魂，9 类风险做全、指标化、沉淀安全态势看板。
  • 整改三态 + 多轮 + 电子签字 是客户审计的关键证据链。
  • 客户评价签字 是服务满意度的直接证据，务必闭环。
  • 工作量统计 建议与工单/巡检/交付自动联动，避免重复填报。
  • 水印 + 防截屏 在移动端实现最有效，PC 端以水印 + 审计为主。
