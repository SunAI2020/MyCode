# 步骤三十九：人脸识别登录（完善方案 P2 · §24.2）

> 依据：V7.0 · §24.2「人脸识别登录与身份核验」
> 范围：后端预留人脸比对接口 + 实现路径说明。

## 1. 目标与方案

人脸识别登录分两段落地：

1. **客户端（已预留）**：移动端用设备级生物识别（uni-app SOTER 人脸/指纹）保护本地 JWT，登录时校验。
2. **后端（本步骤）**：预留 `POST /auth/biometric` 人脸比对接口；`FACE_VERIFY_ENABLED` 开关，未接入人脸 SDK 时明确返回不支持。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `core/config.py` | `FACE_VERIFY_ENABLED` |
| `api/v1/auth.py` | `POST /auth/biometric` 预留端点 |
| `tests/test_biometric.py` | 回归测试 |

## 3. 接口

`POST /auth/biometric`：`{username, face_token}` → 未启用返回「不支持」（需接入人脸比对 SDK：阿里云实人认证 / 商汤 / 腾讯云人脸核身）。
