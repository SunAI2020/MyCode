一、系统是什么

IT运维集中管控平台（ITSM）是「合同 → 子项 → 工单」全链路运维管理系统，由三部分组成：

部分技术作用端口
前端（网页）Vue3浏览器操作5173 / 8080
后端（接口）FastAPI业务逻辑8000
手机 APPuni-app打卡/签到同前端
数据库PostgreSQL存数据5433
缓存 / 检索Redis / ES加速 / 搜索6379 / 9200

一句话：数据库存数据 → 后端算逻辑 → 前端/APP 展示操作。

二、安装前的准备

2.1 Windows（装 3 个软件）

① Docker Desktop：https://www.docker.com/products/docker-desktop/ ，装完重启电脑，图标变绿。验证：docker --version

② Python 3.13：https://www.python.org/downloads/ ，安装务必勾选 Add python.exe to PATH。验证：python --version

③ Node.js 20：https://nodejs.org/ 下载 LTS 版。验证：node -v

2.2 Linux（云服务器）

curl -fsSL https://get.docker.com | bash
apt install -y python3 python3-pip nodejs

三、一键安装

3.1 Windows

双击项目里的 install.bat → 完成后双击 start.bat → 浏览器打开 http://localhost:5173。

3.2 Linux

cd /opt/ITSM
bash install.sh
bash start.sh

3.3 脚本做了什么

步骤命令含义
启动数据库docker compose up -d拉起 PG/Redis/ES
建表alembic upgrade head创建全部表
初始账号python -m app.db.seed写角色 + admin + 初始密码
启动后端uvicorn ... --port 8000后端 8000
启动前端npm run dev前端 5173

四、手动安装详解

# 1. 启动数据库（项目根目录）
docker compose up -d

# 2. 配置后端环境变量
cd backend
copy ..\.env.example .env        # Windows（Linux 用 cp）

# 3. 安装后端依赖 + 建表 + 初始数据
python -m pip install -r requirements.txt
python -m alembic upgrade head
python -m app.db.seed            # 会打印 admin 初始密码

# 4. 启动后端
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# 5. 启动前端（另开窗口）
cd ../frontend
npm install
npm run dev
关键配置 backend/.env：DATABASE_URL=postgresql+psycopg://itsm:itsm_password@localhost:5433/itsm；SECRET_KEY 用 python -c "import secrets;print(secrets.token_urlsafe(32))" 生成。

五、手机 APP 安装

5.1 H5 预览（最快）

cd mobile
npm install
npm run dev:h5

5.2 真机调试（HBuilderX）

下载 HBuilderX → 导入 mobile/ 目录 → 手机连电脑 → 运行到手机。

5.3 打包 App/小程序

HBuilderX → 发行 → 云打包（App）或对应小程序平台（需在 manifest.json 填 appid）。

真机/打包时，改 mobile/src/api/index.ts 的 BASE_URL 为后端实际地址。

六、云服务器部署（阿里云）

# 1. 安全组放行 22/80/443/8000/8080（数据库端口不对外）
# 2. 上传代码到 /opt/ITSM
# 3. 一键安装
bash install.sh
# 4. 生产模式（容器 + nginx，对外 8080）
cp .env.production.example .env.production
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec backend alembic upgrade head
docker compose -f docker-compose.prod.yml exec backend python -m app.db.seed
# 访问 http://服务器IP:8080

七、日常使用操作

7.1 登录

账号 admin，密码为 seed 输出的初始密码。

7.2 七级角色

角色权限
sys_admin 系统管理员全部
sys_ops 系统运维监控/备份
ticket_mgr 工单管理接单/派单/改价
cs_staff 客服只读进度
sec_staff 安服自己的工单 + 签到
cust_admin 客户管理员本客户合同/工单
cust_service 客户服务本客户报障/评价
outsource 外包仅自己被指派任务

前端/APP 菜单按角色自动裁剪。

7.3 数据脱敏（自动）

类型原文客户/外包看到
电话13812341234138****1234
IP10.1.2.310.1.*.*
金额10000***

平台管理员看原文，客户/外包看脱敏值，系统自动完成。

7.4 人脸识别登录（预留）

当前为预留接口（未接入人脸 SDK 返回 501）；客户端用手机自带指纹/面容保护本地登录态。

7.5 打卡拍照（移动端签到）

APP 进入「签到」→ 点「定位」（GPS）→ 点「拍照留证」→ 选签到/签退 → 提交。记录含经纬度+照片+时间。

八、常见问题

问题解决
docker compose 报错确认 Docker Desktop 图标变绿
8000 端口被占用换 --port 8001 并同步前端 proxy 与 CORS
登录密码错误密码是 seed 随机口令，非 admin123
数据库 5433 连不上确认 postgres 容器 running；云上不对外
手机 APP 连不上改 BASE_URL 为后端实际地址
没装 Redis/ES不影响，后端自动降级
彻底卸载docker compose down -v + 删目录
