ITSM 软件设计报告

项目：IT运维集中管控平台 · 版本 V1.0 · 依据《安全运维集中管控平台_完整交付文档》V7.0

一、项目概述

面向安服团队/MSSP，以「合同 → 子项 → 工单」为主轴，统一承载合同履约、内部任务、外包协作、问题整改、交付、绩效、SLA 提醒、AI 增强与知识沉淀。

二、总体架构

2.1 技术栈

层次选型
前端 PCVue3 + Vite + Element Plus + Pinia + ECharts
移动端uni-app（一套代码多端）
后端Python 3.13 + FastAPI + SQLAlchemy 2.0 + Alembic + APScheduler
认证JWT + bcrypt + 七级 RBAC + 行级隔离
数据库PostgreSQL 16 + Redis + Elasticsearch（可降级）
AIOpenAI 兼容 LLM + RAG（可降级）

2.2 分层架构

浏览器/APP → Nginx → FastAPI（api → services → schemas → models → core）
                    → PostgreSQL + Redis + ES

三、数据模型（31 张表）

客户合同、工单、服务、驻场、外包、问题交付、绩效、知识/AI、移动端、系统十大域；核心 ER：customer→contract→contract_item→service_cycle→定期工单，work_order→dispatch→assignee（比例分摊）。

四、关键设计

  • 七级 RBAC + 多租户：scope_filter/assert_scoped 行级隔离 + 字段脱敏 + 外包独立隔离。
  • 可配置工作流：workflow_rule + Approval 审批流（职责分离）。
  • AI 增强：分类/派单建议/摘要/履约洞察/RAG，未配置时确定性降级。
  • 数据安全：脱敏/水印/审计 + EncryptedText 字段加密。
  • 周期拆分 + SLA：split_cycles + add_work_minutes + 分级预警/升级链。

五、部署架构

本地 docker compose + 生产 compose（nginx）+ 阿里云（RDS/Redis/ES/OSS/KMS/SLB/WAF）+ 一键脚本。

六、非功能性

  • 可测试：132 个 pytest 单测。
  • 降级设计：Redis→内存缓存、ES→SQL、LLM→规则。
  • 可观测：统一响应/审计 + /api/v1/health。
  • 安全合规：等保三级对照 + OWASP Top 10。
