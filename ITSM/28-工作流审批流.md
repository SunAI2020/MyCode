# 步骤二十八：工作流审批流（完善方案 P0 · §16.1）

> 依据：V7.0 · §16.1 审批流（派单价超阈值审批 / 报告交付验收审批）
> 范围：通用审批记录模型 + 申请/通过/拒绝端点，审批通过自动执行状态流转并留痕。

## 1. 目标

在状态流转之上增加**审批关卡**：某次流转需经审批人通过后才真正生效。

1. `Approval` 模型（实体/前后态/申请人/审批人/状态/理由/意见）。
2. 申请 / 通过 / 拒绝 / 列表端点。
3. 审批通过 → 调用工作流引擎真正流转 + `action_log` 留痕。

## 2. 文件清单

| 文件 | 说明 |

| `tests/test_approval.py` | 回归测试 |

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/approvals` | 发起审批（校验 to_status 为合法流转目标） |
| POST | `/approvals/{id}/approve` | 通过 → 自动流转 + 留痕 |
| POST | `/approvals/{id}/reject` | 拒绝 → 不流转 |
| GET | `/approvals` | 列表（按状态过滤） |

## 4. 设计

- `Approval` 记录 `from_status → to_status`；通过时用 `assert_transition` 二次校验（防对象状态已变），再 `log_transition` 留痕。
- 支持实体：`work_order` / `change_order` / `outsourcing`。
- 派单价超阈值审批、交付/验收审批作为业务触发点后续接入（P1）。
