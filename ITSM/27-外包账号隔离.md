# 步骤二十七：外包账号隔离（完善方案 P0 · §9.3）

> 依据：《安全运维集中管控平台_完整交付文档.html》V7.0 · §9.3 外包人员权限隔离
> 范围：外包人员账号角色 + 行级隔离（仅见被指派任务）+ 接单/拒单端点。

## 1. 目标

落地 §9.3「外包账号仅见被指派的外包工单，禁止访问客户其他合同/工单/内部数据」：

1. 新增「外包人员」角色（`outsource`）。
2. `OutsourceUser` 绑定登录账号（`user_id`）。
3. 外包任务列表/详情按 `outsource_user_id` 行级隔离。
4. 外包接单（待接单→已接单）/ 拒单（待接单→已拒单）端点。

## 2. 文件清单

| 文件 | 说明 |
|---|---|
| `models/outsourcing.py` | `OutsourceUser.user_id`（绑定账号） |
| `alembic/versions/0012_outsource_user_id.py` | 迁移 |
| `db/seed.py` | 增 `outsource` 角色 |
| `core/deps.py` | `outsourcing_scope_of` |
| `schemas/outsourcing.py` | `OutsourceUser*` 增 `user_id` |
| `api/v1/outsourcing.py` | 行级隔离 + 接单/拒单端点 |
| `tests/test_outsourcing_scope.py` | 回归测试 |

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/outsourcings` | 外包仅见自己的任务；平台见全部 |
| GET | `/outsourcings/{oid}` | 外包仅自己的 |
| POST | `/outsourcings/{oid}/accept` | 外包接单（待接单→已接单） |
| POST | `/outsourcings/{oid}/reject` | 外包拒单（待接单→已拒单） |
| POST | `/outsourcing-reports` | 外包仅为自己的任务提交汇报 |

## 4. 隔离设计

- `outsourcing_scope_of(user, db)`：外包角色返回其 `outsource_user_id`；平台角色返回 `None`（看全部）。
- 外包人员访问他人任务 / 名册 → 403。
