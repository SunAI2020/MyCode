# 步骤四十一：阿里云部署方案（完善方案 P2 · §21）

> 依据：V7.0 · §21 部署架构（阿里云：SLB/WAF/CDN + ECS + RDS PG + Redis + ES + OSS + KMS）
> 范围：将现有 docker-compose 本地部署映射到阿里云，输出迁移方案与安全配置。

## 1. 架构映射（本地 docker → 阿里云）

| 本地 docker 服务 | 阿里云服务 | 说明 |
|---|---|---|
| frontend (nginx) | SLB + CDN + WAF | 静态加速、负载均衡、Web 防火墙 |
| backend (uvicorn) | ECS / ACK 容器 | 应用层（可配 ACK 或 ECS 跑容器） |
| postgres | RDS PostgreSQL（高可用） | 主备 + 自动备份 + SSL 强制 |
| redis | 云数据库 Redis 版 | 会话/缓存/队列 |
| elasticsearch | 阿里云 Elasticsearch | 知识库全文检索 |
| 上传文件 (uploads/) | OSS + CDN | 对象存储（SSE 加密） |
| — | KMS + 安全组 + 云防火墙 | 密钥托管、网络隔离、入侵防护 |

## 2. 迁移步骤

1. **数据层**：开通 RDS PG（高可用，国内 Region）→ 用 `pg_dump` 从本地导出 → `pg_restore` 导入 RDS；开启 SSL 强制连接、TDE、自动备份加密。
2. **对象存储**：开通 OSS，`uploads/` 目录改为 OSS 存储（后端 `UPLOAD_DIR` 换 OSS SDK 上传，或挂 OSSFS）；开启 SSE 加密 + CDN 加速。
3. **缓存/检索**：开通云 Redis + 云 Elasticsearch，配置 `REDIS_URL` / `ELASTICSEARCH_URL` 指向内网地址（VPC 内）。
4. **应用层**：ECS（或 ACK）部署 backend 容器镜像（复用 `backend/Dockerfile`），`ENABLE_SCHEDULER=true` 单实例；配 `SECRET_KEY`/`TRUST_PROXY_HEADERS=true`。
5. **接入层**：SLB（80/443）+ WAF + CDN；TLS 证书（阿里云证书服务）全链路 HTTPS；`nginx.conf` 反代 `/api`、`/uploads`。
6. **安全**：安全组最小开放（仅 80/443 对公网，DB/Redis/ES 仅 VPC 内网可达）；KMS 托管 `SECRET_KEY`（信封加密）；云防火墙 + 审计。

## 3. 数据安全配置（§22）

- **传输**：全链路 TLS 1.2+（SLB↔应用↔RDS）；RDS PG `ssl=require`。
- **静态加密**：RDS TDE；OSS SSE；KMS 信封加密 `SECRET_KEY`；应用层敏感列加密（`EncryptedText`，已有）。
- **脱敏/水印/审计**：应用层已落地（`mask_sensitive` + 前端水印 + `sys_audit_log`）。

## 4. 高可用

- RDS PG 主备 + 跨可用区；ECS 多可用区 + SLB 健康检查（复用 `/api/v1/health`）；Redis 主备；ES 多节点。

## 5. 说明

- 本方案为**迁移蓝图**，实际开通需阿里云账号与资源配额；本地 docker 已可演示全部业务能力。
- 后端容器镜像与迁移/备份脚本已在步骤二十二交付，可直接复用。
