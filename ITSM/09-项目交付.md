# 步骤九：项目交付（阶段三 · FR-11）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §4.10 / §6.2
> 范围：四类核心报告 + 专项报告的交付管理。

## 1. 目标

实现交付管理：挂接合同/子项/工单层级，记录四类核心报告与专项报告，支持客户签署验收。

## 2. 表（1 张，依据 §6.2）

`delivery` 交付：`id, work_order_id, contract_id, contract_item_id, title, report_type, report_id, sign`

## 3. 报告类型

- 四类核心：运维报告 / 发现问题报告 / 整改报告 / 验收报告
- 专项：漏洞扫描 / 渗透测试 / 应急演练 / 安全评估 / 基线核查 / 等保测评 / 驻场服务月报

## 4. API

- `GET/POST /deliveries`
- `GET/PUT/DELETE /deliveries/{id}`
- `POST /deliveries/{id}/sign` 客户签署验收（客户侧角色可签署本客户交付）

## 5. 权限与隔离

- 写：sys_admin/sys_ops/ticket_mgr；删：sys_admin/sys_ops
- 客户侧角色经 `contract_id → customer` 行级隔离；签署允许平台 + 客户侧角色（`assert_scoped`）
