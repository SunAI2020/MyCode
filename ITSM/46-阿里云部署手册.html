一、购买云服务器（ECS）

参数推荐值
地域国内（华东1杭州）
规格2 核 4G 起（建议 4 核 8G）
镜像Ubuntu 22.04 64 位
系统盘高效云盘 40G
登录凭证密钥对（推荐）
安全组入方向只放行：22（SSH）、80、443、8080。切勿放行 5433/6379/9200/8000（数据库/后端只内网访问）。

二、操作系统初始配置

ssh root@公网IP
apt update && apt upgrade -y
apt install -y curl wget git vim unzip net-tools
timedatectl set-timezone Asia/Shanghai
hostnamectl set-hostname itsm-server
# 加 swap（2核4G 防内存不足）
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile

三、软件环境

# Docker + Compose
curl -fsSL https://get.docker.com | bash
# Python
apt install -y python3 python3-pip python3-venv
# Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
# Nginx
apt install -y nginx

四、数据库

方式 A（默认）：项目 docker-compose.prod.yml 自带 PG/Redis/ES，上传代码后 docker compose up 即拉起，无需单独装。

方式 B（生产推荐）：阿里云 RDS PostgreSQL 16，与 ECS 同 VPC，白名单加 ECS 内网 IP，改 DATABASE_URL 为 RDS 内网地址。

五、上传软件与导入数据

# 上传代码
cd /opt && git clone 仓库地址 ITSM
# 本地导出数据库
bash scripts/backup.sh
# 上传备份并导入（服务器上）
scp backups/itsm_xxx.dump root@公网IP:/opt/ITSM/backups/
cd /opt/ITSM && bash scripts/restore.sh backups/itsm_xxx.dump

六、端口与安全组

服务端口对外
nginx 前端8080✅ 公网
后端8000❌ 仅内网
PostgreSQL5432（容器内网）❌
Redis / ES6379 / 9200❌

七、协议（HTTP/HTTPS）

# HTTP 先跑通：http://公网IP:8080
# HTTPS：域名 A 记录指向服务器后
apt install -y certbot python3-certbot-nginx
certbot --nginx -d itsm.example.com
certbot renew --dry-run   # 验证自动续期

八、一键部署生产

cd /opt/ITSM
cp .env.production.example .env.production   # 填 SECRET_KEY + POSTGRES_PASSWORD
POSTGRES_PASSWORD=强密码 docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec backend alembic upgrade head
docker compose -f docker-compose.prod.yml exec backend python -m app.db.seed
# 访问 http://公网IP:8080

九、调试与验证

docker compose -f docker-compose.prod.yml ps              # 看状态
curl http://localhost:8000/api/v1/health                  # 后端健康
docker compose -f docker-compose.prod.yml logs -f backend # 看日志

十、故障处置

现象解决
公网访问不通安全组放行 8080；确认 nginx 容器 healthy
SSH 连不上安全组放行 22
数据库连不上看 postgres 容器状态；核对 DATABASE_URL
后端 500看 backend 日志，多为环境变量缺失
seed 报数据库不存在先 alembic upgrade head
证书失败先加域名 A 记录再 certbot
内存不足被杀加 swap；升级 4 核 8G
ES 起不来调小 ES_JAVA_OPTS 或注释掉（系统自动降级）
