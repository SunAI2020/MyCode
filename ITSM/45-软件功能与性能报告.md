## 五、安全特性

| 项 | 实现 |
|---|---|
| 身份鉴别 | JWT + bcrypt，无弱默认口令 |
| 访问控制 | 七级 RBAC + 行级/字段级隔离 |
| 数据脱敏 | 电话/IP/金额自动遮蔽 |
| 数据加密 | 敏感列 Fernet 加密 + 口令哈希 |
| 审计 | before/after + 真实 IP + 时间 |
| 水印 | 前端用户名+日期水印 |
| 防越权 | 7 轮安全审查 + IDOR/跨租户防护 |
