# 步骤一：工程骨架与基础设施

> 依据文档：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §9.1 阶段一
> 本步骤定位：搭出可运行的后端 + 前端 + 数据库骨架，为后续业务开发打底。

## 1. 目标

跑通「本机可运行空壳系统」：PostgreSQL（Docker）→ FastAPI 后端（Swagger 可访问）→ Vue3 前端（登录页占位可访问），三者通过 `.env` + vite 代理串起来。

## 2. 交付物清单

| 文件 | 作用 |
|---|---|
| `docker-compose.yml` | 拉起 PostgreSQL 16（`postgres:16-alpine`），数据卷持久化，预留 Redis 注释位 |
| `.env.example` | `DATABASE_URL` / `SECRET_KEY` / `ACCESS_TOKEN_EXPIRE_MINUTES` 模板 |
| `README.md` | 项目说明 + 一键启动步骤 |
| `backend/requirements.txt` | fastapi / uvicorn / sqlalchemy / psycopg / pydantic-settings / pyjwt / passlib / alembic / apscheduler |
| `backend/app/main.py` | FastAPI 入口：`/api/v1` 路由挂载、CORS、健康检查、Swagger |
| `backend/app/core/config.py` | pydantic-settings 读取 `.env` |
| `backend/app/db/session.py` / `base.py` | SQLAlchemy 2.0 engine / SessionLocal / Declarative Base（本步不建表，Alembic 在步骤二） |
| `backend/app/utils/response.py` | 统一响应 `{"code":0,"message":"ok","data":{}}` + 分页 |
| `frontend/` | Vite + Vue3 + Element Plus + Pinia + Vue Router + Axios 脚手架 |

## 3. 技术要点

- **后端**：FastAPI + Uvicorn；`pydantic-settings` 读 `.env`；SQLAlchemy 2.0（`psycopg` 驱动）。
- **统一响应契约**（文档 §7.1）：`/api/v1` 前缀、`{"code":0,"message":"ok","data":{}}`、分页 `?page=&size=`。
- **前端**：Vite 代理 `/api` → `http://localhost:8000`；axios 拦截器统一带 JWT、统一解析 `code`。

## 4. 验证方式

```bash
# 1. 数据库
docker compose up -d
# 2. 后端
cd backend && python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
# 打开 http://localhost:8000/docs 应看到 Swagger；GET /api/v1/health 返回 ok
# 3. 前端
cd frontend && npm install && npm run dev
# 打开 http://localhost:5173 应看到登录页占位
```
