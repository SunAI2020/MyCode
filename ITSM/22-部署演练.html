步骤二十二：部署演练（阶段六 · 本地部署 → 生产迁移）

依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · §8.6 阶段六 · §10.1 上线部署步骤
范围：应用容器化 + 生产编排 + 迁移/备份/回滚脚本 + 数据初始化补全 + 部署手册。

1. 目标

把「开发模式（uvicorn --reload + npm run dev）」补齐为可演练的一键生产部署：

  • 应用容器化：后端 Dockerfile + 前端 Dockerfile（多阶段构建）+ nginx 反向代理。
  • 生产编排：docker-compose.prod.yml 编排 backend / frontend(nginx) / postgres / redis / es。
  • 迁移 / 备份 / 回滚：scripts/ 三脚本。
  • 数据初始化补全：seed 增 SLA 模板 + 知识库种子。
  • 真实 IP 透传：get_current_user 优先读 X-Forwarded-For。
  • 部署手册：本地部署 → 迁移演练 → 回滚预案 → 验收清单。

3. 部署步骤（生产）

cp .env.production.example .env.production
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml exec backend alembic upgrade head
docker compose -f docker-compose.prod.yml exec backend python -m app.db.seed
# 访问 http://localhost:8080（nginx），API http://localhost:8000/docs

4. 备份 / 恢复 / 回滚

bash scripts/backup.sh
bash scripts/restore.sh backups/itsm_xxx.dump

5. 验证

docker compose -f docker-compose.prod.yml config
bash -n scripts/*.sh
cd backend && python -m pytest -q

6. 说明

  • 调度器单实例：ENABLE_SCHEDULER=true 时后端须单实例，避免重复生成定期工单。
  • 真实 IP：生产经 nginx 反代，审计 IP 改读 X-Forwarded-For 首段。
  • 移动端（uni-app）单独开一个阶段，不在本步骤范围。
