步骤 49 · 合同原件导入与智能提取

目标

合同管理页新增「合同原件」导入：上传 PDF/Word 原件 → 加密存档 → 智能识别并自动提取合同要素 → 弹窗表格展示、供人工修改补充 → 确认后自动生成「客户 → 合同 → 服务对象 → 服务项目」全链路。

关键决策（用户已确认）

  1. 文件存储：原件 Fernet 加密后存本地磁盘 uploads/contracts/，数据库只存元数据（哈希/加密文件名/大小/提取字段），不存 BLOB。
  2. 确认后落地：自动生成全链路（客户 → 合同 → 服务对象 → 服务项目）。

交互流程

「导入存档」→ 选文件(.pdf/.docx)
  → POST /contract-archives/upload：校验 → 抽文本 → LLM 抽取 → 加密写盘 → 建待确认行
  → 返回 archive_id + 抽取字段 → 前端弹窗编辑
  → POST /contract-archives/{id}/confirm：匹配/新建客户 → 建合同 → 建服务对象 → 建服务项目 → 归档
  → 返回合同 → 刷新列表

变更内容

  • 依赖：pypdf、python-docx。
  • 加密：app/services/archive_crypto.py，密钥来自持久化密钥文件 uploads/contracts/.archive.key（跨重启稳定），可选 ARCHIVE_ENC_KEY 覆盖。
  • 模型：Contract 加 5 列；新增 ContractArchive。
  • 抽取服务：app/services/contract_extract_service.py（LLM+降级）。
  • API：app/api/v1/contract_archives.py（upload / confirm / list / download）。
  • 迁移：0022_contract_archive.py。
  • 前端：Contracts.vue 加「导入存档」+ 抽取结果编辑弹窗。
  • 测试：test_contract_archive.py。

安全说明

  • 加密传输：生产由 nginx 终止 TLS；文件落盘前已 Fernet 加密（静态加密覆盖开发/直连）。
  • 脱敏：提取结果中的金额等敏感字段对客户侧角色按 mask_sensitive 脱敏。
  • 行级隔离：归档按 customer_id 隔离；待确认行仅本次会话可见。
  • 类型/大小：仅 .pdf/.docx，上限 20MB。
