# 步骤二十：后台代码审查 8 项缺陷修复（阶段五收尾加固）

> 依据：《IT运维集中管控平台_软件设计方案.html》V1.0 定稿 · 全量代码审查
> 范围：修复 `/code-review` 返回的 8 项缺陷（4 实质正确性 + 4 健壮性/一致性），并补回归测试。

## 1. 缺陷与修复方案

| # | 文件 | 缺陷 | 修复 |
|---|------|------|------|
| 1 | `utils/wo_no.py` | SQLite 取号竞态：线程锁只串行化 `max(no)` 读取，不覆盖后续 INSERT+commit | 新增 `work_order_no_scope(db)` 上下文管理器（PG 用事务级咨询锁、非 PG 用线程锁），锁跨越「取号+插入+commit」；3 个调用点（work_orders / portal / scheduler jobs）改为 `with` 包裹 |
| 2 | `schemas/work_order.py` | `WorkOrderOut` 缺 `description` 字段，工单描述在所有响应中被丢弃 | 补 `description: str \| None = None` |
| 3 | `core/deps.py` | `owning_customer_id` 与 `scope_filter` 不解析 `contract_item_id`，仅经子项关联的 Delivery/WorkOrder 对客户侧不可见 | 归属链路与 scope_filter 的 WorkOrder/Delivery 分支补 `contract_item_id → ContractItem → Contract` 左连接 |
| 4 | `services/change_service.py` | `set_conflict_flag` 在 `ci_id` 变更时只重算新 CI，旧 CI 兄弟的过期冲突标记不解除 | `set_conflict_flag` 增 `previous_ci_id` 形参，旧 CI 活跃兄弟一并重算；`update_change_order` 传入变更前 ci_id |
| 5 | `api/v1/portal.py` | `create_ticket` 未校验子项是否属于请求指定的 `contract_id`，可造跨合同错配 | 补「子项属于指定合同」一致性校验（客户侧/平台侧均适用） |
| 6 | `api/v1/performance.py` | `update_performance` 显式传 null 时 `float(None)` → 500 | 显式 null 直接 400（列 NOT NULL，不可清空） |
| 7 | `services/cycle_service.py` | `generate_cycles` 幂等仅依赖 `cycle_no`，schedule 变更后残留旧日期周期 | 重建前删除该子项「pending + auto_generated」旧周期，已 started/done 保留历史 |
| 8 | `services/search_service.py` | `_search_kb_es` 的 `total` 取自 ES（含已删除陈旧文档），与 DB `items` 不一致 → 分页虚高/末页空洞 | `total` 改以 DB `search_articles(...).count()` 为准（ES 仅作排序/候选），与 SQL 降级路径一致 |

## 2. 回归测试

- `test_work_order.py`（新）：`WorkOrderOut` 含 `description`。
- `test_row_isolation.py`（扩）：仅经 `contract_item_id` 关联的 WorkOrder/Delivery 对客户侧可见。
- `test_portal.py`（扩）：`contract_item_id` 与 `contract_id` 错配被拒。
- `test_performance_service.py`（扩）：显式 null 更新被拒 400。
- `test_change_service.py`（扩）：`ci_id` 变更后旧 CI 冲突标记解除。
- `test_cycle_service.py`（扩）：schedule 变更后重新生成不残留旧日期周期。

## 4. 说明

- 修复 1 只影响非 PostgreSQL（SQLite 开发/测试）取号并发；生产 PostgreSQL 走事务级咨询锁（本就跨进程安全），行为不变。
- 修复 8 中 `total` 改由 DB 统计，`q` 走 SQL `ilike` 近似全文（与既有降级路径一致）；ES 仅提供候选排序，不再虚高。
