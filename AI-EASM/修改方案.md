## 用户补充需求 — 企业全维度搜索
搜索企业信息时，需要对以下**12类标识符**一并进行搜索和交叉查询：

| 类别 | 标识符 | 搜索用途 |
|------|--------|---------|
| 1 | 企业名称 | 主搜索词，全维度资产发现 |
| 2 | 简称 | 替代搜索词，覆盖非正式命名 |
| 3 | 曾用名称 | 历史资产追溯，发现已更名但未迁移的资产 |
| 4 | 法人 | WHOIS/ICP反查、GitHub代码提交者搜索 |
| 5 | 股东 | 股权穿透、关联企业发现 |
| 6 | 实际受益人 | UBO识别、关联资产追溯 |
| 7 | 实际控制人 | 控制链追溯、隐性关联发现 |
| 8 | 关联企业 | 股权/供应链/业务关联方全量资产发现 |
| 9 | 股东上下关联企业 | 向上(谁投资了股东)和向下(股东还投资了谁)穿透 |
| 10 | 邮箱 | 域名关联、代码提交记录、泄露数据库碰撞 |
| 11 | 电话 | ICP备案反查、WHOIS反查 |
| 12 | 手机号码 | 微信/APP/社交平台关联、泄露数据库碰撞 |

**核心原则**: 输入一个企业名称 → 系统自动发散搜索上述全部12类标识符 → 每类标识符作为新的搜索种子 → 递归发现更多关联资产 → 结果合并去重后统一展示

  │
  └─ Step 5: 合并去重

**核心算法: BFS+标识符发散搜索**:
```
输入: 企业名称 "A集团有限公司"
  │
  ├─ Level 0: 查询A的企业档案
  │    ├─ 提取: 简称A科技、曾用名B科技、法人张三、股东李四(40%)、股东王五(25%)
  │    ├─ 提取: 邮箱 hr@a.com、电话 010-12345678、手机 138****8888
  │    └─ 写入 enterprise_profiles + identifier_index
  │
  ├─ 发散搜索 (基于Level 0提取的标识符):
  │    ├─ 法人张三 → 天眼查反查 → 发现企业C、企业D → 加入队列
  │    ├─ 股东李四 → 天眼查反查 → 发现企业E(李四持股60%) → 加入队列
  │    ├─ 股东王五 → 天眼查反查 → 发现企业F(王五持股35%) → 加入队列
  │    ├─ 邮箱 hr@a.com → WHOIS反查 → 发现域名 g.cn → 归属企业G
  │    ├─ 电话 010-12345678 → ICP反查 → 发现2个备案域名 → 关联企业H
  │    └─ 简称"A科技" → 全文搜索 → 发现代码仓库泄露、文档泄露
  │
  ├─ Level 1-4: 对每个新发现的企业递归执行Level 0的发散搜索
  │    └─ 控制: visited集合防循环, max_depth=4
  │
  └─ 输出: 企业关系图谱 + 全量资产列表 + 标识符关联链路
```

## Phase 3: AI置信度评分升级

### 3.1 重写 `core/ai_search_engine.py` — `_ai_confidence_scoring()`

从当前简单3规则升级为7因子加权评分模型:

```python
def _ai_confidence_scoring(self, org_name, results):
    """7因子贝叶斯加权置信度评分"""
    for r in results:
        factors = {}
        score = 0.0

        # 因子1: DNS解析验证 (权重0.25)
        if self._is_dns_resolved(r):
            factors['dns_verified'] = 1.0
            score += 0.25

        # 因子2: 证书CN/SAN匹配组织名 (权重0.20)
        cert_score = self._cert_matches_org(r, org_name)
        factors['cert_match'] = cert_score
        score += cert_score * 0.20

        # 因子3: 名称相似度 (权重0.15)
        sim = self._name_similarity(r.get('asset_name',''), org_name)
        factors['name_similarity'] = sim
        score += sim * 0.15

        # 因子4: 多源交叉验证 (权重0.15)
        source_count = len(set(r.get('sources', [r.get('source','')])))
        multi = min(source_count / 3.0, 1.0)
        factors['multi_source'] = multi
        score += multi * 0.15

        # 因子5: ICP备案确认 (权重0.10)
        icp_score = 1.0 if self._icp_confirms(r, org_name) else 0.0
        factors['icp_confirm'] = icp_score
        score += icp_score * 0.10

        # 因子6: 网站指纹匹配 (权重0.10)
        fp_score = 1.0 if self._fingerprint_matches(r) else 0.0
        factors['fingerprint_match'] = fp_score
        score += fp_score * 0.10

        # 因子7: WHOIS注册人匹配 (权重0.05)
        whois_score = 1.0 if self._whois_matches_org(r, org_name) else 0.0
        factors['whois_match'] = whois_score
        score += whois_score * 0.05

        r['confidence'] = min(score, 0.98)
        r['confidence_factors'] = json.dumps(factors, ensure_ascii=False)

        # 置信度分级标签
        if r['confidence'] >= 0.85:
            tag = '高可信度-确认资产'
        elif r['confidence'] >= 0.65:
            tag = '中可信度-待确认'
        elif r['confidence'] >= 0.40:
            tag = '低可信度-疑似影子资产'
        else:
            tag = '需人工研判'
```
